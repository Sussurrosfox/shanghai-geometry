本项目遵循 `design.md` 设计规范与上海中学竞赛教材原著结构，将《上海中学竞赛课程：平面几何》第 01 至 08 单元（涵盖 7 个讲座专题与 1 个阶段综合习题模块，总计 95 道精选竞赛题目）全面制成现代化、交互式的 **Quarto Book**。

```

├── data/
```

## 三、核心特色与实现

1. **题目全要素独立页面 (95/95)**
   - **元数据标签栏**：显示所属讲座/练习模块、竞赛难度评级以及核心知识点标签；
   - **题目与高清构型图**：公式清洗规范化，剔除多余的重复题头与切片残留标记；
   - **练习一专属双图拆分算法**：原书版面排布在奇数题末尾的两两并排图例，经 `build_content.py` 算法实现 100% 精确拆分与一对一归位；
   - **原书标准解答**：以 `callout-important` 折叠块呈现标准证明或求解过程；
   - **解题思路与分析**：讲座例题配有 `callout-note`，还原竞赛思维探索过程与辅助线构思动机；
   - **分步证明推理**：配有 `callout-tip`，提供精细化几何步骤推理；
   - **交互式动态演示**：讲座例题内嵌 580px 自适应 iframe 演示，并提供新窗口独立全屏交互链接。

2. **跨章节导航与全局检索**
   - 包含 8 个模块的大类导航树；
   - 左侧抽屉式侧边栏，支持章节折叠与展开；
   - 顶部集成 Quarto 客户端全局模糊搜索，支持快速查找题号、定理名称与关键词。

3. **数学公式与排版引擎**
   - 采用 KaTeX 快速渲染引擎；
   - 自定义注入宏包，解决 `\bigtriangleup`、`\ang`、`\parallelogram`、`\sim` 等特殊几何符号；
   - 消除段落缩进避免 Pandoc 误识别为代码块导致公式不渲染；
   - 自动转换 `align*`、`gather*` 环境与公式内 `&` 转义。

## 五、常用命令与操作指南

### 1. 重新生成全书内容（从原材料重新提取）
```powershell
python scripts/build_content.py
```

### 2. 执行质量门禁核验
```powershell
python scripts/validate_content.py
```

### 3. 本地编译与实时预览
```powershell
# 编译全书为静态 HTML 站点
quarto render --to html

# 启动本地热重载预览服务器
quarto preview
```

编译产物位于 `quarto-book/_site/`，使用任意现代浏览器双击打开 `_site/index.html` 即可直接阅读、检索全书与操作交互演示。

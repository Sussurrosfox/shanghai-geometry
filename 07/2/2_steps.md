# 2 — 分步证明文字

## 步骤 0：题设构型与几何元素

圆 ω₁ 与圆 ω₂ 分别以 O₁、O₂ 为圆心相交于两点 X, Y。直线 l₁ 过 O₁ 交 ω₂ 于 P, Q 两点；直线 l₂ 过 O₂ 交 ω₁ 于 R, S 两点。已知点 P, Q, R, S 四点共圆于圆 ω₃（圆心为 O₃，半径为 r₃）。目标求证：圆心 O₃ 必然落在两圆的公共弦所在直线 XY（即 ω₁ 与 ω₂ 的根轴）上。

## 步骤 1：点 O₁ 关于圆 ω₂ 与 ω₃ 的圆幂等式

因为点 P, Q 是圆 ω₂ 与圆 ω₃ 的交点，割线 l₁（即直线 PQ）是两圆的公共弦（根轴）。已知直线 l₁ 经过点 O₁，故点 O₁ 在圆 ω₂ 与 ω₃ 的根轴上。由根轴的基本性质，点 O₁ 关于圆 ω₂ 与 ω₃ 的圆幂相等：O₁O₂² - r₂² = O₁O₃² - r₃²   …… ①

## 步骤 2：点 O₂ 关于圆 ω₁ 与 ω₃ 的圆幂等式

同理，点 R, S 是圆 ω₁ 与圆 ω₃ 的交点，割线 l₂（即直线 RS）是两圆的公共弦（根轴）。已知直线 l₂ 经过点 O₂，故点 O₂ 在圆 ω₁ 与 ω₃ 的根轴上。由根轴的基本性质，点 O₂ 关于圆 ω₁ 与 ω₃ 的圆幂相等：O₁O₂² - r₁² = O₂O₃² - r₃²   …… ②

## 步骤 3：作差消元，导出圆心距离平方关系

将 ① 式与 ② 式两端作差（① - ②）：(O₁O₂² - r₂²) - (O₁O₂² - r₁²) = (O₁O₃² - r₃²) - (O₂O₃² - r₃²)左端 O₁O₂² 相互抵消，右端半径平方 r₃² 相互抵消，整理得到：r₁² - r₂² = O₁O₃² - O₂O₃²移项即得：O₂O₃² - r₂² = O₁O₃² - r₁²

## 步骤 4：点 O₃ 关于圆 ω₁ 与 ω₂ 的圆幂相等

观察上式两端：等号左端为点 O₃ 关于圆 ω₂ 的圆幂 Pow(O₃, ω₂)；等号右端为点 O₃ 关于圆 ω₁ 的圆幂 Pow(O₃, ω₁)。因此点 O₃ 对圆 ω₁ 与 ω₂ 的圆幂严格相等！根据根轴判定定理，关于两圆圆幂相等的点的集合必为该两圆的根轴，故 O₃ 必然落在圆 ω₁ 与 ω₂ 的根轴上。

## 步骤 5：命题得证（圆心 O₃ 落在直线 XY 上）

因为圆 ω₁ 与圆 ω₂ 相交于点 X 与点 Y，它们的根轴正是公共弦所在直线 XY！结合上一步的结论，圆心 O₃ 必然严格落在直线 XY 之上。原命题完全得证！注：从深层几何看，l₁ 与 l₂ 交于根心 M，O₃ 恰为 △MO₁O₂ 的垂心，XY 为第三条高，三高共点天然闭合。

# 07/2 几何证明分步规划与代数解算报告（例 1）

## 1. 命题背景与几何定理

### 1.1 题目陈述
**例 1**：设圆 $\omega_1$ 与圆 $\omega_2$ 交于两点 $X, Y$，直线 $l_1$ 过圆 $\omega_1$ 的圆心 $O_1$，且交圆 $\omega_2$ 于 $P, Q$ 两点，直线 $l_2$ 过圆 $\omega_2$ 的圆心 $O_2$ 且交圆 $\omega_1$ 于 $R, S$ 两点。  
**求证**：若 $P, Q, R, S$ 在一个圆上，则该圆的圆心在直线 $XY$ 上。

### 1.2 核心定理体系
1. **根轴与圆幂性质**：
   - 若两圆相交于两点 $X, Y$，则直线 $XY$ 为两圆的公共弦，即为其根轴。
   - 平面上任意一点 $M$ 关于圆 $\omega(O, r)$ 的圆幂定义为 $\text{Pow}(M, \omega) = MO^2 - r^2$。
   - 点 $M$ 落在两圆根轴上的充要条件是：点 $M$ 关于两圆的圆幂相等。
2. **两割线共圆判据与根心定理**：
   - 割线 $l_1(PQ)$ 是圆 $\omega_2$ 与圆 $\omega_3$ 的公共割线，若它们相交于 $P, Q$，则 $l_1$ 即为 $\omega_2$ 与 $\omega_3$ 的根轴。
   - 割线 $l_2(RS)$ 是圆 $\omega_1$ 与圆 $\omega_3$ 的公共割线，若它们相交于 $R, S$，则 $l_2$ 即为 $\omega_1$ 与 $\omega_3$ 的根轴。
   - $P, Q, R, S$ 四点共圆 $\iff$ 割线 $l_1$ 与 $l_2$ 的交点 $M$ 落在圆 $\omega_1$ 与 $\omega_2$ 的根轴 $XY$ 上（三圆根轴共点于根心 $M$）。
3. **垂心对偶机制（深层几何洞察）**：
   - 因为 $l_1$ 是 $\omega_2, \omega_3$ 的公共弦所在直线，故连心线 $O_2O_3 \perp l_1$（即 $O_2O_3 \perp MO_1$）；
   - 因为 $l_2$ 是 $\omega_1, \omega_3$ 的公共弦所在直线，故连心线 $O_1O_3 \perp l_2$（即 $O_1O_3 \perp MO_2$）；
   - 在 $\triangle MO_1O_2$ 中，$O_2O_3$ 与 $O_1O_3$ 为边 $MO_1, MO_2$ 上的两条高线，其交点 $O_3$ 即为 $\triangle MO_1O_2$ 的**垂心**！
   - 而直线 $XY \perp O_1O_2$ 是过顶点 $M$ 垂直于底边 $O_1O_2$ 的第三条高线。根据三角形三高共点定理，垂心 $O_3$ 必在直线 $XY$ 上！

## 2. 严格代数几何坐标解算与验证

### 2.1 坐标系建立与解析推导
为保证图形视觉对称沉稳、水平连心线最利于观察，建立直角坐标系：
- 设连心线 $O_1O_2$ 为水平线，$y = 338.00$。
- 设 $O_1 = (210.00, 338.00)$，半径 $r_1 = 130.00$。
- 设 $O_2 = (410.00, 338.00)$，半径 $r_2 = 150.00$。
- 圆心距 $d = |O_1O_2| = 200.00$。

#### 根轴方程求解
根轴上的任意点 $(x, y)$ 满足：
$$(x - x_{O_1})^2 + (y - y_{O_1})^2 - r_1^2 = (x - x_{O_2})^2 + (y - y_{O_2})^2 - r_2^2$$
代入 $y_{O_1} = y_{O_2} = 338$：
$$(x - 210)^2 - 130^2 = (x - 410)^2 - 150^2$$
$$x^2 - 420x + 44100 - 16900 = x^2 - 820x + 168100 - 22500$$
$$400x = 118400 \implies x = 296.00$$
故根轴为铅垂直线：**$x = 296.00$**。

#### 公共弦交点 $X, Y$ 坐标
在圆 $\omega_1$ 方程中代入 $x = 296$：
$$(296 - 210)^2 + (y - 338)^2 = 130^2$$
$$86^2 + (y - 338)^2 = 16900 \implies 7396 + (y - 338)^2 = 16900$$
$$(y - 338)^2 = 9504 \implies |y - 338| = \sqrt{9504} \approx 97.488$$
取上交点为 $X$，下交点为 $Y$：
- $X = (296.00, 338.00 - 97.488) = (296.00, 240.51)$
- $Y = (296.00, 338.00 + 97.488) = (296.00, 435.49)$

#### 割线 $l_1, l_2$ 与交点 $P, Q, R, S$
- 直线 $l_1$ 过 $O_1(210, 338)$ 与根心 $M(296, 279)$，斜率 $k_1 = \frac{279 - 338}{296 - 210} = \frac{-59}{86} \approx -0.6860$。
  解其与圆 $\omega_2: (x-410)^2 + (y-338)^2 = 150^2$ 的交点得到：
  - $P = (264.52, 301.44)$
  - $Q = (431.40, 189.53)$
- 直线 $l_2$ 过 $O_2(410, 338)$ 与根心 $M(296, 279)$，斜率 $k_2 = \frac{279 - 338}{296 - 410} = \frac{-59}{-114} \approx 0.5175$。
  解其与圆 $\omega_1: (x-210)^2 + (y-338)^2 = 130^2$ 的交点得到：
  - $R = (167.29, 215.22)$
  - $S = (334.22, 299.66)$

#### 外接圆 $\omega_3$ 圆心 $O_3$ 与半径 $r_3$
由垂心关系，在 $\triangle MO_1O_2$ 中，高线垂心 $O_3$ 落在根轴 $x = 296.00$ 上：
- $O_3 = (296.00, 168.00)$
- 半径 $r_3 = 137.10$

### 2.3 视口与包围盒解算（解决顶部截断问题）
- **图元包围盒（Bounding Box）**：
  - $x$ 范围：$[O_1.x - r_1, O_2.x + r_2] = [210 - 130, 410 + 150] = [80.00, 560.00]$（宽 480.00px，中心 $x = 320.00$）
  - $y$ 范围：$[O_3.y - r_3, O_2.y + r_2] = [168 - 137.10, 338 + 150] = [30.90, 488.00]$（高 457.10px，中心 $y = 259.45$）
- **视口配置**：`viewBox="0 0 640 520"`
  - 左边留白：$80.00 - 0 = 80.00\text{px}$
  - 右边留白：$640 - 560.00 = 80.00\text{px}$（左右完全等距居中）
  - 顶端留白：$30.90 - 0 \approx 31\text{px}$
  - 底端留白：$520 - 488.00 = 32.00\text{px}$（上下完全等距居中）
  - **结论**：彻底根除旧版本负坐标导致圆 $\omega_3$ 顶部边缘被剪切的严重缺陷，图元四周呼吸留白极度舒适。

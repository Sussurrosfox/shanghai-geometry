# 例 3 分步证明与图元增删规划 (07/4/steps.md)

## 一、 几何命题与代数坐标解算

### 1. 题目命题重述
已知圆 $O$ 与圆 $\Gamma$ 交于 $A, B$ 两点，点 $O$ 在圆 $\Gamma$ 上，且在 $AB$ 上的投影为 $S$。直线 $OS$ 与圆 $\Gamma$ 交于点 $P$。$\angle ASP$ 的平分线与 $\odot O$ 交于点 $L$，且 $A, L$ 在直线 $OP$ 的同侧。$K$ 为圆 $\Gamma$ 上的点，满足 $PS = PK$，且 $A, K$ 在直线 $OP$ 的同侧。证明：$SL = KL$。

---

### 2. 严格代数几何解算与参数设计

建立直角坐标系，设圆 $\Gamma$ 为标准圆：
- 取圆心 $\Gamma$ 位于 $(0, 1)$，半径 $R_\Gamma = 1$。
- 点 $O$ 为原点 $(0, 0)$，点 $P = (0, 2)$。则线段 $OP$ 即为圆 $\Gamma$ 沿 $y$ 轴方向的一条直径。
- 设直线 $PQ$ 与负 $y$ 轴（射线 $PO$）的夹角为 $\theta$。为了获得视觉舒展、无退化、点位清晰分布的图形，选定 $\theta = 48^\circ$。
- 点 $S$ 位于 $OP$ 上，坐标为 $(0, y_S)$。由已知条件 $PS = PK$ 且 $K$ 在以 $OP$ 为直径的圆 $\Gamma$ 上，直角 $\triangle PKO$ 中 $PK = PO \cos\theta = 2 \cos\theta$。因此：
  $$y_S = 2 - 2\cos\theta = 2(1 - \cos 48^\circ) \approx 0.66207$$
  $$PS = PK = 2\cos 48^\circ \approx 1.33793$$
- 直线 $AB \perp OP$ 于 $S$，故直线 $AB$ 水平方程为 $y = y_S$。
- 圆 $O$ 以 $O(0,0)$ 为圆心，半径 $R_O = \sqrt{OA^2} = \sqrt{2 y_S} \approx 1.15071$。
- 点 $A, B$ 为直线 $y = y_S$ 与圆 $\Gamma$ 的交点：
  $$x_A = \sqrt{2 y_S - y_S^2} \approx 0.94105, \quad A = (0.94105, 0.66207), \quad B = (-0.94105, 0.66207)$$
- 点 $Q$ 为直线 $PK$ 与直线 $AB$ 的交点：在直角 $\triangle PSQ$ 中，$x_Q = PS \cdot \tan\theta \approx 1.48629$，$Q = (1.48629, 0.66207)$。
- 斜边 $PQ = \frac{PS}{\cos\theta} = 2.0 = PO$（严格恒等！）。
- 点 $K$ 位于射线 $PQ$ 上：
  $$K = (PK \sin\theta, 2 - PK \cos\theta) = (1.33793 \sin 48^\circ, 2 - 1.33793 \cos 48^\circ) \approx (0.99427, 1.10464)$$
- $\triangle QSP$ 的内心 $L$：
  在直角 $\triangle QSP$ 中，$S$ 为直角顶点，内切圆半径：
  $$r_{\text{in}} = \frac{PS + QS - PQ}{2} = \frac{1.33793 + 1.48629 - 2.0}{2} \approx 0.41211$$
  故内心 $L = (r_{\text{in}}, y_S + r_{\text{in}}) \approx (0.41211, 1.07418)$。
- 严格几何验证：
  - 点 $L$ 到 $O$ 的距离：$OL = \sqrt{0.41211^2 + 1.07418^2} \approx 1.15071 = R_O$（在圆 $O$ 上！）。
  - 点 $L$ 到 $S$ 的距离：$SL = \sqrt{0.41211^2 + 0.41211^2} \approx 0.58282$。
  - 点 $L$ 到 $K$ 的距离：$KL = \sqrt{(0.99427-0.41211)^2 + (1.10464-1.07418)^2} \approx 0.58282$。
  - $SL - KL = 0$（严格相等！浮点误差 $< 10^{-16}$）。
  - 外接圆 $\Gamma'$（$Q, K, L, S, O$ 五点共圆）：以 $OQ$ 为直径，圆心为 $Q/2 \approx (0.74314, 0.33104)$，半径 $R_{\Gamma'} = \frac{OQ}{2} \approx 0.81347$。

## 三、 详细分步推理与图元增删清单

### 步骤 0：已知条件与图形
- **标题**：✦ 已知条件与几何构型
- **正文**：
  已知 $\odot O$ 与 $\odot \Gamma$ 交于 $A, B$ 两点，$O \in \odot \Gamma$ 且在 $AB$ 上的正交投影为 $S$。<br>
  直线 $OS$ 与 $\odot \Gamma$ 交于点 $P$；$\angle ASP$ 的平分线与 $\odot O$ 交于点 $L$（$A, L$ 在 $OP$ 同侧）。<br>
  点 $K \in \odot \Gamma$ 满足 $PS = PK$（$A, K$ 在 $OP$ 同侧）。<br>
  <b>求证</b>：$SL = KL$。
- **画面图元**：
  - 显示点：$O, P, S, A, B, K, L$。
  - 显示线段：$OP$、$AB$、$PS$（高亮）、$PK$（高亮虚线）。
  - 角平分线：射线 $SL$（绿色虚线）。
  - 标记：$S$ 处直角标记；$PS$ 与 $PK$ 的等长单刻度标记。

### 步骤 1：构造割线交点 $Q$ 与四点共圆
- **标题**：① 延长割线相交，得出四点共圆 $Q, K, S, O$
- **正文**：
  延长 $PK$ 与 $BA$ 的延长线交于点 $Q$。<br>
  因为 $OP$ 是圆 $\Gamma$ 的直径，所以圆周角 $\angle OKP = 90^\circ$（即 $OK \perp PQ$）。<br>
  又因为 $OS \perp AB$ 于 $S$，所以 $\angle QSP = 90^\circ$（即 $\angle QSO = 90^\circ$）。<br>
  由于 $\angle QSO = \angle QKO = 90^\circ$，四边形 $QSKO$ 对角互补，故 <b>$Q, K, S, O$ 四点共圆于 $\Gamma'$</b>，且 $OQ$ 为其直径。
- **画面图元**：
  - 新增点：$Q$。
  - 新增线段：$A$ 到 $Q$ 的延长线段（青色虚线）、$K$ 到 $Q$ 的延长线段（青色虚线）、线段 $OK$、$OQ$（蓝色虚线）。
  - 新增辅助圆：以 $OQ$ 为直径的圆 $\Gamma'$（紫色虚线圆）。
  - 新增标记：$K$ 处直角标记 $\angle OKP$、$S$ 处直角标记 $\angle QSO$。

### 步骤 2：直角三角比导出等腰对称 $PO = PQ$
- **标题**：② 利用直角三角形余弦关系，导出 $PO = PQ$
- **正文**：
  在直角 $\triangle PSQ$ 中（$\angle PSQ = 90^\circ$），有 $\cos\angle QPO = \frac{PS}{PQ}$。<br>
  在直角 $\triangle PKO$ 中（$\angle PKO = 90^\circ$），有 $\cos\angle QPO = \frac{PK}{PO}$。<br>
  因为已知 $PS = PK$，所以分母必然相等：<b>$PQ = PO$</b>！<br>
  这说明 $\triangle PQO$ 是以 $P$ 为顶点的等腰三角形，两腰上的高 $QS$ 与 $OK$ 完全对称且全等。
- **画面图元**：
  - 高亮多边形：半透明填充直角 $\triangle PSQ$（浅蓝）与直角 $\triangle PKO$（浅黄）。
  - 高亮线段：$PO$ 与 $PQ$（橙色高亮加粗双线）。
  - 标记：公共顶角 $\angle QPO$ 的角弧（橙色）；$PO$ 与 $PQ$ 处的等长双刻度标记。

### 步骤 3：内心角计算，确立五点共圆
- **标题**：③ 设内心 $L'$，证明 $Q, K, L', S, O$ 五点共圆
- **正文**：
  设直角 $\triangle QSP$ 的内心为 $L'$。根据三角形内心的基本角度性质：<br>
  $$\angle QL'S = 90^\circ + \frac{1}{2}\angle QPS = 90^\circ + \frac{1}{2}\angle QPO$$<br>
  在等腰 $\triangle PQO$ 中，底角 $\angle QOP = 90^\circ - \frac{1}{2}\angle QPO$，故：<br>
  $$\angle QL'S = 180^\circ - \angle QOP = 180^\circ - \angle QOS$$<br>
  因此四边形 $Q L' S O$ 对角互补，说明点 $L'$ 也在过 $Q, S, O$ 的外接圆 $\Gamma'$ 上！<br>
  结合前述结果，<b>$Q, K, L', S, O$ 五点共圆于 $\Gamma'$</b>，且 $OQ$ 仍为其直径。
- **画面图元**：
  - 显示内心点：$L'$（标记在 $L$ 位置，用特别醒目的颜色显示）。
  - 辅助连线：线段 $QL', SL', PL'$。
  - 显示辅助圆：圆 $\Gamma'$（紫色醒目显示）。
  - 角弧标记：$\angle QL'S$ 与 $\angle QOS$ 互补角弧对比。

### 步骤 4：同弧圆周角与三角形相似 $QL'^2 = QK \cdot QP$
- **标题**：④ 导角证明相似三角形 $\triangle QL'K \sim \triangle QPL'$
- **正文**：
  在圆 $\Gamma'$ 中，由同弧所对圆周角相等得 $\angle QL'K = \angle QSK$。<br>
  又 $\angle QSK = 90^\circ - \angle KSP$；在等腰 $\triangle PSK$（$PS = PK$）中，底角 $\angle KSP = 90^\circ - \frac{1}{2}\angle KPS$。<br>
  于是 $\angle QSK = \frac{1}{2}\angle KPS$。而 $PL'$ 是 $\triangle QSP$ 的内角平分线，故 $\frac{1}{2}\angle KPS = \angle KPL'$。<br>
  由此得到 $\angle QL'K = \angle QPL'$！<br>
  结合公共角 $\angle L'QK$，可得 <b>$\triangle QL'K \sim \triangle QPL'$</b>，从而有：<br>
  $$\frac{QL'}{QP} = \frac{QK}{QL'} \implies QL'^2 = QK \cdot QP$$
- **画面图元**：
  - 高亮相似三角形：$\triangle QL'K$（紫色填充）与 $\triangle QPL'$（青色填充）。
  - 相等角标记：$\angle QL'K$ 与 $\angle QPL'$ 画同色等角度标记弧线。
  - 辅助连线：$L'K$、$L'P$。

### 步骤 5：根轴圆幂与同一法确定 $L = L'$
- **标题**：⑤ 结合根轴圆幂与勾股定理，证明 $L$ 与 $L'$ 重合
- **正文**：
  由于 $AB$ 是圆 $O$ 与圆 $\Gamma$ 的根轴，$Q$ 在直线 $AB$ 上，由圆幂定理：<br>
  $$QK \cdot QP = QA \cdot QB = QO^2 - OA^2$$<br>
  又因 $OQ$ 是圆 $\Gamma'$ 的直径，$L'$ 在圆 $\Gamma'$ 上，故 $\angle QL'O = 90^\circ$。在直角 $\triangle QL'O$ 中有 $QO^2 = QL'^2 + OL'^2$。<br>
  结合上一小步结论代入：<br>
  $$QL'^2 = (QL'^2 + OL'^2) - OA^2 \implies OL'^2 = OA^2 \implies OL' = OA$$<br>
  这表明<b>内心 $L'$ 位于圆 $O$ 上</b>！又 $L'$ 落在 $\angle ASP$ 的平分线上，故 <b>$L'$ 与题目中的点 $L$ 完全重合</b>。
- **画面图元**：
  - 高亮割线与根轴：割线 $Q-A-B$ 及割线 $Q-K-P$。
  - 直角三角形：直角 $\triangle QL'O$ 高亮（直角标记 $\angle QL'O = 90^\circ$）。
  - 动态显示半径：$OL'$ 与 $OA$ 用蓝色粗线高亮，并标记等长刻度。

### 步骤 6：底边中垂线性质，得出最终结论
- **标题**：⑥ 等腰三角形顶角平分线即中垂线，证得 $SL = KL$
- **正文**：
  既然点 $L$ 即为 $\triangle QSP$ 的内心，射线 $PL$ 即为等腰三角形 $\triangle PSK$ 顶角 $\angle SPK$ 的角平分线。<br>
  因为 $PS = PK$，由等腰三角形“三线合一”性质，<b>$PL$ 必为底边 $SK$ 的垂直平分线</b>。<br>
  点 $L$ 位于中垂线 $PL$ 上，因此到两端点距离必然相等：<br>
  $$SL = KL$$<br>
  命题得证！∎
- **画面图元**：
  - 辅助线：底边 $SK$（红色实线）、中垂线 $PL$（橙色加粗）。
  - 高亮目标线段：$SL$ 与 $KL$（鲜红加粗线条，带双等长红色刻度线）。
  - 直角标记：$PL$ 与 $SK$ 垂足处的直角标记。
  - 显示结论成就标语徽章。

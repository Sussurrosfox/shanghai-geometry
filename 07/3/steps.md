# 07/3 几何证明步骤规划（例 2）

## 1. 题面阐释与核心结论
- **题目来源**：高中数学竞赛课程讲义 第二册 第 07 讲 例 2（图 6-4）
- **已知条件**：
  - 锐角 $\triangle ABC$ 中，$AB > AC$；
  - $H$ 为其垂心，$AD \perp BC$ 于点 $D$；
  - $E, F$ 分别在射线 $AB, AC$ 上且线段 $EF$ 经过点 $D$；
  - $B, E, C, F$ 四点共圆，其圆心记为 $U$；
  - $M$ 为边 $BC$ 的中点。
- **求证**：四边形 $MUDH$ 为平行四边形（顶点顺时针顺序为 $M-H-D-U$）。
- **几何本质与核心转化**：
  - 延长高线 $AD$ 与 $\triangle ABC$ 外接圆交于点 $K$。
  - 由垂心对称性质知 $D$ 是 $HK$ 的中点，即 $DH = DK = \frac{1}{2}HK$。
  - 由圆幂定理 $AD \cdot DK = BD \cdot DC = ED \cdot DF$，导出 $A, E, K, F$ 四点共圆（圆心记为 $V$）。
  - 点 $K$ 实为完全四边形 $AEBDCF$ 的**密克点 (Miquel Point)**，满足 $\angle AEK = \angle AFK = 90^\circ$，因此 $AK$ 即为圆 $AEKF$ 的直径，$V$ 为 $AK$ 中点。
  - 由连心线垂直公共弦得 $UV \perp EF$；由反平行角性质得 $AO \perp EF$，从而 $UV \parallel AO$。
  - 结合 $OU \parallel AV$（均垂直于 $BC$），得出四边形 $OAVU$ 为平行四边形，从而 $OU = AV$。
  - 最终转化线段关系：$MU = OU - OM = AV - \frac{1}{2}AH = \frac{1}{2}AK - \frac{1}{2}AH = \frac{1}{2}HK = DH$。
  - 一组对边 $MU \parallel DH$ 且 $MU = DH$，对角线 $MD$ 与 $HU$ 互相平分于中点，严格证得四边形 $MUDH$（即 $MHDU$）为平行四边形。

- $B = (160.00, 360.00)$
- $C = (520.00, 360.00)$
- 底边长 $a = 360.00$，底边水平位于 $y = 360.00$
- $M = \text{mid}(B, C) = (340.00, 360.00)$
- $A = (395.00, 100.00)$（$x_A - x_M = 55.00 > 0$，满足 $AB > AC$）

由几何关系精确解算的其他点坐标：
- **垂足 $D$**：$AD \perp BC \implies D = (395.00, 360.00)$
- **垂心 $H$**：在 $x = 395.00$ 上，满足 $BH \perp AC$：
  $$y_H = 360.00 - \frac{(395 - 160)(520 - 395)}{360 - 100} = 360.00 - \frac{235 \times 125}{260} \approx 247.02$$

- **外心 $O$ 与外接圆半径 $R_O$**：

- **密克交点 $K$**：
  延长高线 $AD$ 与外接圆第二交点，亦即 $H$ 关于 $BC$ 的对称点：
  $$y_K = 2 \times 360.00 - 247.02 = 472.98, \quad K = (395.00, 472.98)$$
- **圆心 $V$ 与半径 $R_V$**：
  $V = \text{mid}(A, K) = (395.00, 286.49)$，$R_V = |A - V| = 186.49$
  *(注意：$V$ 与 $O$ 严格处于同一水平线 $y = 286.49$，间距为 $55.00$)*
- **割线垂足 $E, F$（西姆松垂足）**：
  $E = \text{foot}(K, AB) = (209.46, 305.28)$
  $F = \text{foot}(K, AC) = (540.65, 402.96)$
  验证共线：$D, E, F$ 斜率误差 $< 10^{-12}$，西姆松线严格过垂足 $D$。
- **圆心 $U$ 与半径 $R_U$**：
  四点 $B, E, C, F$ 共圆圆心位于 $BC$ 中垂线 $x = 340.00$ 上：
  $$y_U = 472.98, \quad U = (340.00, 472.98), \quad R_U = 212.52$$
  *(注意：$U$ 与 $K$ 严格处于同一水平线 $y = 472.98$，间距为 $55.00$)*

### (3) 核心几何代数关系严格验证结果

2. $\vec{UM} = (0, -112.98) = \vec{DH}$，误差 $< 2 \times 10^{-13}$；

## 4. 分步演示与图元增删清单（Step 0 ~ 5）

### Step 0：已知构型与几何元素
- **标题**：已知条件与几何构型
- **正文**：
  锐角 $\triangle ABC$ 中，$AB > AC$，$H$ 为垂心，高线 $AD \perp BC$ 于点 $D$。
  点 $E, F$ 分别在射线 $AB, AC$ 上且线段 $EF$ 经过点 $D$；
  $B, E, C, F$ 四点共圆，圆心为 $U$；$M$ 为边 $BC$ 的中点。
  **求证**：四边形 $MUDH$ 为平行四边形。
- **画面图元**：
  - 底层：$\triangle ABC$、高线 $AD$、垂足直角标记、割线 $EF$、底边中点 $M$、圆 $BECF$（浅色）。
  - 顶层点：$A, B, C, D, M, H, E, F, U$。

### Step 1：延长高线引入辅助点 $K$
- **标题**：① 延长高线 $AD$ 与外接圆相交于点 $K$
- **正文**：
  作 $\triangle ABC$ 的外接圆 $\odot O$。延长高线 $AD$ 与外接圆相交于点 $K$。
  由外接圆经典垂心对称性质，垂心 $H$ 关于边 $BC$ 的对称点必落在外接圆上。
  因为 $BC$ 为对称轴且 $AD \perp BC$，所以垂足 $D$ 为线段 $HK$ 的中点，即：
  $$DH = DK = \frac{1}{2}HK$$
- **画面图元**：
  - 新增外接圆 $\odot O$（蓝色细虚线）及外心 $O$。
  - 新增延长高线 $DK$（红色虚线）及点 $K$。
  - 高亮等长线段 $DH$ 与 $DK$（红色双刻度线 mark）。

### Step 2：圆幂定理导出 $A, E, K, F$ 四点共圆
- **标题**：② 圆幂定理与密克点性质（$AK$ 为直径）
- **正文**：
  在圆 $\odot O$ 中，由相交弦定理得：$AD \cdot DK = BD \cdot DC$。
  在圆 $\odot U$ 中，割线 $EF$ 与 $BC$ 相交于点 $D$，得：$ED \cdot DF = BD \cdot DC$。
  两式联立立即得到：$AD \cdot DK = ED \cdot DF$。
  由相交弦定理的逆定理，**$A, E, K, F$ 四点共圆**（设其圆心为 $V$）。
  点 $K$ 实为完全四边形 $AEBDCF$ 的**密克点**，从而 $E, B, K, D$ 与 $D, K, F, C$ 均四点共圆。
  由于 $KD \perp BC$（$\angle KDC = 90^\circ$），导出 $\angle AFK = \angle AEK = 90^\circ$。
  因此，**$AK$ 为圆 $AEKF$ 的直径**，圆心 $V$ 即为线段 $AK$ 的中点。
- **画面图元**：
  - 新增圆 $AEKF$（橙色虚线圆）及圆心点 $V$。
  - 新增直角标记 $\angle AFK = 90^\circ$ 与 $\angle AEK = 90^\circ$（橙色直角符号）。
  - 高亮直径线段 $AK$。

### Step 3：双垂直导出平行 $UV \parallel AO$
- **标题**：③ 连心线与反平行线导出 $UV \parallel AO$
- **正文**：
  1. 圆 $\odot U$（即圆 $BECF$）与圆 $\odot V$（即圆 $AEKF$）相交于两点 $E, F$，公共弦为 $EF$。
     两圆连心线必垂直平分公共弦，故 **$UV \perp EF$**。
  2. 导角证明 $AO \perp EF$：
     在圆 $\odot O$ 中，$\angle OAC = 90^\circ - B$；
     在圆内接四边形 $BECF$ 中，外角 $\angle AFE = \angle B$。
     在 $\triangle APF$ 中（设 $AO$ 延长线交 $EF$ 于 $P$），
     $\angle PAF + \angle PFA = (90^\circ - B) + B = 90^\circ$。
     因此 **$AO \perp EF$**。
  3. 因为两线均垂直于直线 $EF$，故 **$UV \parallel AO$**。
- **画面图元**：
  - 新增线段 $UV$ 与线段 $AO$（橙色高亮粗线，带双平行箭头）。
  - 标示垂足交点与垂直记号 $UV \perp EF$、$AO \perp EF$。

### Step 4：构造平行四边形 $OAVU$
- **标题**：④ 构造平行四边形 $OAVU \implies OU = AV$
- **正文**：
  因为 $O$ 为外心、$M$ 为 $BC$ 中点，所以中垂线 $OM \perp BC$；
  又点 $U$ 为弦 $BC$ 所在圆的圆心，亦在 $BC$ 中垂线上，故直线 $OU \perp BC$。
  而高线 $ADK \perp BC$，即直线 $AV \perp BC$。
  因此，**$OU \parallel AV$**。
  结合前一步已证的 **$UV \parallel AO$**，
  四边形 $OAVU$ 的两组对边分别平行，
  因此 **四边形 $OAVU$ 为平行四边形**！由此得到对边相等：
  $$OU = AV$$
- **画面图元**：
  - 高亮平行四边形 $OAVU$（半透明橙色填充与橙色边框）。
  - 在边 $OU$ 与 $AV$ 上添加平行与等长标记。

### Step 5：转化线段长度得出最终结论
- **标题**：⑤ 线段等长 $MU = DH \implies$ 四边形 $MUDH$ 为平行四边形
- **正文**：
  由欧拉线经典性质，外心到中点的距离等于顶点到垂心距离的一半，即 $OM = \frac{1}{2}AH$。
  因为 $V$ 是直径 $AK$ 的中点，所以 $AV = \frac{1}{2}AK$。
  将平行四边形对边 $OU = AV$ 代入，得：
  $$MU = OU - OM = AV - \frac{1}{2}AH = \frac{1}{2}AK - \frac{1}{2}AH = \frac{1}{2}HK = DH$$
  因为直线 $MU \perp BC$ 且直线 $DH \perp BC$，故 **$MU \parallel DH$**；
  再结合 **$MU = DH$**，一组对边平行且相等；
  （同时，线段 $MD$ 与 $HU$ 的中点重合于同一对称中心 $((367.5, 360))$，对角线互相平分）。
  因此，**四边形 $MUDH$（顶点顺序 $M-H-D-U$）为严格的平行四边形**！命题得证。
- **画面图元**：
  - 绿色高亮平行四边形 $MUDH$（绿色半透明填充、绿色粗实线框边）。
  - 绘制两条互相平分的对角线 $MD$ 与 $HU$（绿色虚线）。
  - 高亮对边 $MU$ 与 $DH$（等长双刻度线与平行符号）。

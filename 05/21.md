设点 $P, Q$ 为边长为 1 的正方形 ${ABCD}$ 内的两个点,求 ${AP} + {BP} + {PQ} + \; {QC} + {QD}$ 的最小值.

证明

如图,将 $\bigtriangleup {PAB}$ 绕点 $A$ 顺时针旋转 ${60}^{ \circ  }, B$ 绕至点 ${B}^{\prime }, P$ 绕至 ${P}^{\prime }$ ,则 $\bigtriangleup {AP}{P}^{\prime }$ 为正三角形.

类似地,将 $\bigtriangleup {QDC}$ 绕点 $D$ 逆时针旋转 ${60}^{ \circ  }, C$ 绕至 ${C}^{\prime }, Q$ 绕至 ${Q}^{\prime }$ ,则 $\bigtriangleup {DQ}{Q}^{\prime }$ 为正三角形.

经上述变换后,可知 ${AP} + {BP} + {PQ} + {QC} + {QD} = {B}^{\prime }{P}^{\prime } + {P}^{\prime }P + {PQ} + Q{Q}^{\prime } + \; {Q}^{\prime }{C}^{\prime } \geq  {B}^{\prime }{C}^{\prime } = 1 + 2\sin {60}^{ \circ  } = 1 + \sqrt{3}.$

所求最小值为 $\sqrt{3} + 1$ .

# 2 — 分步证明文字

## 步骤 0：已知条件与几何构型

点 P 为圆 O 外一点，从 P 引两条切线 PA, PB，切点为 A, B。
连线 PO 垂直平分切点弦 AB 于点 M，并与圆 O 割于点 I。
过点 M 任作一条不同于 AB 的割弦 CD。
求证目标：点 I 是 △PCD 的内心。

## 步骤 1：① 切线直角与射影定理

连接圆半径 OA。因 PA 切圆于 A，切线垂直于半径，故 OA ⊥ PA，即 ∠PAO = 90°。
由对称性知割线 PO 垂直平分弦 AB，故 AM ⊥ PO。
在直角三角形 Rt△PAO 中，应用射影定理：
PA² = PM · PO
同时圆心距满足关系：OM · OP = OA² = R²。

## 步骤 2：② 延长直径构建调和点列

延长线段 PO 交圆 O 于另一点 E，则线段 IE 是圆 O 的一条直径，O 为其中心。
由圆幂定理（切割线定理），有 PA² = PI · PE。
结合步骤 ① 可得：
PM · PO = PI · PE
因为 O 是 IE 的中点，且 OM · OP = OI² = OE² = R²。
根据调和分割的牛顿公式，点 P, M 关于线段 IE 调和共轭，即点列满足：
(P, M; I, E) = -1   （即 PI / IM = PE / EM）

## 步骤 3：③ 连接 ID, ED 导出正交调和线束

连接线段 ID 与 ED。
由于线段 IE 为圆 O 的直径，而点 D 位于圆周上，由圆周角定理可知：直径所对的圆周角为直角，即：
∠IDE = 90°   (即 DI ⊥ DE)
以圆周上的点 D 为透视中心投影直线 PE 上的调和点列，得到以 D 为顶点的调和线束：
D(P, M; I, E) = -1

## 步骤 4：④ 正交调和线束推出 DI 平分 ∠PDC

在调和线束 D(P, M; I, E) = -1 中，共轭射线满足 DI ⊥ DE。
调和线束核心定理：若调和线束的一对共轭射线相互垂直，则这对射线必为另一对共轭射线夹角的内、外角平分线！
因此射线 DI 平分射线 DP 与 DM 的夹角 ∠PDM。
因为点 C, M, D 共线，射线 DM 即为射线 DC，所以：
DI 平分 ∠PDC   (即 ∠PDI = ∠CDI)

## 步骤 5：⑤ 同理对称性推导 CI 平分 ∠PCD

同理，连接 IC 与 EC。
由于 IE 为直径且 C 在圆周上，故 ∠ICE = 90°（即 CI ⊥ CE）。
从点 C 投影调和点列 P, I, M, E，得到调和线束：
C(P, M; I, E) = -1   且   CI ⊥ CE
同理可得射线 CI 平分 ∠PCM，即：
CI 平分 ∠PCD   (即 ∠PCI = ∠DCI)

## 步骤 6：⑥ 角平分线交汇判定内心，结论得证

在 △PCD 中：
由步骤 ④，DI 是内角 ∠PDC 的角平分线；
由步骤 ⑤，CI 是内角 ∠PCD 的角平分线。
三角形两内角平分线的交点即为该三角形的内心（Incenter）。
两条平分线均过点 I 且相交于点 I，故点 I 必为 △PCD 的内心。
同时第三条内角平分线 PI 亦汇交于 I。
原命题完整得证！

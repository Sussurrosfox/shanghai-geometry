# 费尔巴哈定理（例 6）分步证明规划

## 题目内容
**定理（费尔巴哈定理，Feuerbach's Theorem）**：
任意一个三角形的九点圆与其内切圆和三个旁切圆都相切。

---

## 步骤规划总览（共 7 步：Step 0 ~ Step 6）

### Step 0: 构型引入：九点圆、内切圆与旁切圆
- **标题**：构型引入：九点圆、内切圆与旁切圆
- **讲解正文**：
  在任意不等边锐角 $\triangle ABC$ 中，记三边中点为 $A_1, B_1, C_1$。过这三点的圆就是 $\triangle ABC$ 的**九点圆**（欧拉圆），圆心记为 $N$。
  $\triangle ABC$ 的内心为 $I$，内切圆切 $BC$ 于点 $X$；顶点 $A$ 对应的旁切圆心为 $I_a$，切 $BC$ 边于点 $X_a$。
  **费尔巴哈定理**断言：九点圆与内切圆 $\odot I$ 相切，且与三个旁切圆（如 $\odot I_a$）也都相切。本演示将采用以底边中点 $A_1$ 为反演中心的经典反演几何法进行严谨证明。
- **画面图元清单**：
  - 基础三角形 $\triangle ABC$（深色线段）
  - 三边中点 $A_1, B_1, C_1$
  - 九点圆 $\odot N$（蓝色细实线）
  - 内心 $I$ 与内切圆 $\odot I$（绿色细实线），切点 $X$
  - 旁心 $I_a$ 与旁切圆 $\odot I_a$（紫色细实线），切点 $X_a$
  - 标注顶点 $A, B, C$ 与关键点 $A_1, B_1, C_1, I, X, X_a$

---

### Step 1: 边中点 A1 与切点 X, Xa 的对称性质
- **标题**：切点对称性：$A_1$ 是 $XX_a$ 的中点，$A_1X = A_1X_a = \frac{1}{2}|b-c|$
- **讲解正文**：
  记 $\triangle ABC$ 的三边长分别为 $a = BC, b = CA, c = AB$，半周长 $p = \frac{1}{2}(a+b+c)$。不妨设 $b > c$。
  由切线长性质易知：
  $BX = p - b = \frac{a - b + c}{2}$，
  $CX_a = p - b$。
  由于 $A_1$ 为边 $BC$ 的中点，即 $BA_1 = CA_1 = \frac{a}{2}$，从而：
  $A_1X = BA_1 - BX = \frac{a}{2} - (p - b) = \frac{1}{2}(b - c)$，
  $A_1X_a = CA_1 - CX_a = \frac{a}{2} - (p - b) = \frac{1}{2}(b - c)$。
  由此得出关键对称性：**$A_1$ 不仅是 $BC$ 的中点，也是线段 $XX_a$ 的中点**，且 $A_1X = A_1X_a = \frac{1}{2}(b - c)$。
- **画面图元清单**：
  - 高亮底边 $BC$ 上的分段线段 $BX, A_1X, A_1X_a, X_aC$
  - 重点标注中点 $A_1$ 与切点 $X, X_a$
  - 标明等长线段 $A_1X = A_1X_a = \frac{1}{2}(b-c)$，突出以 $A_1$ 为对称中心的几何布局

---

### Step 2: 引入第二条内公切线 B'C'，证明四点共线
- **标题**：引入第二条内公切线 $B'C'$，$A, I, S, I_a$ 四点共线
- **讲解正文**：
  底边 $BC$ 是内切圆 $\odot I$ 与旁切圆 $\odot I_a$ 的一条内公切线。两圆必有另一条对称的内公切线，记为 $B'C'$（其中 $B' \in AC, C' \in AB$），且 $B'C'$ 与 $BC$ 相交于点 $S$。
  由于两条内公切线关于连心线 $I I_a$ 轴对称，而内切圆与旁切圆的连心线正是 $\angle A$ 的内角平分线，因此交点 $S$ 必落在角平分线上，即 **$A, I, S, I_a$ 四点共线**！
  由角平分线定理：$SC = \frac{ab}{b+c}, SB = \frac{ac}{b+c}$，
  从而 $SA_1 = \frac{1}{2}(SC - SB) = \frac{a(b-c)}{2(b+c)}$。
- **画面图元清单**：
  - 绘制内角平分线 $AS$（浅红点划线，穿过 $A, I, S, I_a$）
  - 绘制第二条内公切线 $B'C'$（橙色实线），标注点 $S, B', C'$
  - 高亮显示 $BC$ 与 $B'C'$ 关于角平分线 $AS$ 的对称轴关系

---

### Step 3: 作中位线交公切线，分析相似三角形
- **标题**：中位线交公切线，相似三角形导出距离比例
- **讲解正文**：
  连接中位线 $A_1B_1$（$\parallel AB$）与 $A_1C_1$（$\parallel AC$），分别与内公切线 $B'C'$ 交于点 $B''$ 与 $C''$。
  由对称性可知：切线段长 $AC' = AC = b \implies BC' = AC' - AB = b - c$；同理 $CB' = b - c$。
  利用中位线平行线构造相似三角形：
  因 $A_1B'' \parallel BC'$，故 $\triangle SA_1B'' \sim \triangle SBC'$，得：
  $\frac{A_1B''}{BC'} = \frac{SA_1}{SB} \implies \frac{A_1B''}{b-c} = \frac{\frac{a(b-c)}{2(b+c)}}{\frac{ac}{b+c}} = \frac{b-c}{2c} \implies A_1B'' = \frac{(b-c)^2}{2c}$。
  同理，因 $A_1C'' \parallel CB'$，由 $\triangle SA_1C'' \sim \triangle SCB'$ 得：
  $\frac{A_1C''}{b-c} = \frac{SA_1}{SC} = \frac{b-c}{2b} \implies A_1C'' = \frac{(b-c)^2}{2b}$。
- **画面图元清单**：
  - 绘制中位线 $A_1B_1, A_1C_1$（青色细线）
  - 标出交点 $B'' = B'C' \cap A_1B_1$ 和 $C'' = B'C' \cap A_1C_1$
  - 高亮相似三角形 $\triangle SA_1B''$ 与 $\triangle SBC'$，加注平行标记

---

### Step 4: 建立以 A1 为中心、半径为 (b-c)/2 的反演变换
- **标题**：建立以 $A_1$ 为中心、半径 $\frac{1}{2}(b-c)$ 的反演变换
- **讲解正文**：
  中位线长度为 $A_1B_1 = \frac{c}{2}, A_1C_1 = \frac{b}{2}$。将它们与前一步求出的 $A_1B'', A_1C''$ 相乘：
  $A_1B'' \cdot A_1B_1 = \frac{(b-c)^2}{2c} \cdot \frac{c}{2} = \left(\frac{b-c}{2}\right)^2$，
  $A_1C'' \cdot A_1C_1 = \frac{(b-c)^2}{2b} \cdot \frac{b}{2} = \left(\frac{b-c}{2}\right)^2$。
  这揭示了一个惊人的反演对偶关系！
  以 $A_1$ 为反演中心、以 $R_{inv} = \frac{1}{2}(b-c)$ 为反演半径建立反演变换：
  - 边中点 $B_1$ 的反演像恰好是 $B''$！
  - 边中点 $C_1$ 的反演像恰好是 $C''$！
  - 反演圆 $\Gamma_{inv}$ 的半径恰为 $A_1X = A_1X_a = \frac{1}{2}(b-c)$，故反演圆过两切点 $X$ 与 $X_a$！
- **画面图元清单**：
  - 绘制反演圆 $\Gamma_{inv}$（圆心 $A_1$，半径 $R_{inv}$，橙色虚线圆）
  - 标注反演圆经过 $X$ 和 $X_a$
  - 高亮共线点对 $(A_1, B'', B_1)$ 与 $(A_1, C'', C_1)$ 及其反演幂乘积关系

---

### Step 5: 九点圆反演为公切线 B'C'，证明与内切圆切于点 T
- **标题**：九点圆反演为直线 $B'C'$，导出与内切圆切于点 $T$
- **讲解正文**：
  根据反演变换的基本定理：
  1. 九点圆经过反演中心 $A_1$，且经过 $B_1, C_1$。由于 $B_1, C_1$ 的反演像分别为 $B'', C''$，因此**九点圆的反演像正是经过 $B'', C''$ 的直线，即内公切线 $B'C'$**！
  2. 线段 $A_1X$ 在切线 $BC$ 上，切内切圆 $\odot I$ 于 $X$，其切线长恰为 $A_1X = R_{inv}$。由反演性质，从反演中心引出的切线长等于反演半径的圆与反演圆正交，因此**内切圆 $\odot I$ 的反演像就是它自身**！
  3. 因为内公切线 $B'C'$ 与内切圆 $\odot I$ 相切于点 $T'$，反演变换保持相切关系（保角性），所以直线 $B'C'$ 的像（九点圆）与圆 $I$ 的像（圆 $I$ 自身）必相切！
  其切点 $T$ 恰好是 $T'$ 关于反演圆的像，即九点圆与内切圆相切于点 $T$！
- **画面图元清单**：
  - 高亮九点圆 $\odot N$ 与其反演像直线 $B'C'$
  - 标出公切线切点 $T'$（$B'C'$ 与 $\odot I$ 的切点）
  - 标出费尔巴哈切点 $T$（九点圆与 $\odot I$ 的切点）
  - 绘制从 $A_1$ 穿过 $T$ 至 $T'$ 的反演射线，生动体现反演对应

---

### Step 6: 同理与旁切圆 Ia 相切，完成费尔巴哈定理证明
- **标题**：同理与旁切圆相切，费尔巴哈定理获证
- **讲解正文**：
  完全类似地：
  从反演中心 $A_1$ 到旁切圆 $\odot I_a$ 的切线长为 $A_1X_a = R_{inv}$，故**旁切圆 $\odot I_a$ 的反演像也是其自身**！
  公切线 $B'C'$ 切旁切圆 $\odot I_a$ 于点 $T_a'$，反演后九点圆与旁切圆 $\odot I_a$ 必然相切于点 $T_a$（$T_a$ 为 $T_a'$ 的反演像）！
  同理，以其余两边中点 $B_1, C_1$ 为反演中心，亦可分别证明九点圆与另外两个旁切圆 $\odot I_b, \odot I_c$ 都相切。
  至此，**任意三角形的九点圆与其内切圆和全部三个旁切圆都相切**！费尔巴哈定理完整获证！
- **画面图元清单**：
  - 标出旁切圆切点 $T_a'$ 与费尔巴哈切点 $T_a$
  - 同时清晰呈现九点圆与内切圆 $\odot I$（切于 $T$）以及旁切圆 $\odot I_a$（切于 $T_a$）的相切状态
  - 全局高亮九点圆与两圆的费尔巴哈相切点，展示定理的和谐对称与深刻几何美

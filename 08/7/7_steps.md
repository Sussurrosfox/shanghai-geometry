# 7 — 分步证明文字

## 步骤 0：构型引入：九点圆、内切圆与旁切圆

在任意不等边锐角 $\triangle ABC$ 中，记三边中点为 A₁, B₁, C₁，其外接圆即为三角形的九点圆（圆心为 N）。
           $\triangle ABC$ 的内心为 I，内切圆切边 $BC$ 于点 X；顶点 $A$ 对应的旁切圆心为 Iₐ，切边 $BC$ 于点 Xₐ。
           费尔巴哈定理断言：九点圆与内切圆及三个旁切圆都相切。我们将以底边中点 A₁ 为中心，运用反演几何完成严谨证明。

## 步骤 1：切点对称性：A₁ 是 XXₐ 的中点

记三边长为 $a, b, c$，半周长 $p = \frac{1}{2}(a+b+c)$，不妨设 $b > c$。
           由切线长性质易知：$BX = CX_a = p - b = \frac{a - b + c}{2}$。
           因为 $A_1$ 是边 $BC$ 的中点，即 $BA_1 = CA_1 = \frac{a}{2}$，从而：
           $A_1X = BA_1 - BX = \frac{a}{2} - (p - b) = \frac{1}{2}(b - c)$，
           $A_1X_a = CA_1 - CX_a = \frac{a}{2} - (p - b) = \frac{1}{2}(b - c)$。
           结论：A₁ 是线段 XXₐ 的中点，且 $A_1X = A_1X_a = \frac{1}{2}(b - c)$！

## 步骤 2：第二条内公切线 B'C' 与四点共线

底边 $BC$ 是圆 $I$ 与圆 $I_a$ 的内公切线。两圆必有另一条对称的内公切线 B'C'（$B' \in AC, C' \in AB$），且与 $BC$ 交于点 S。
           两内公切线关于连心线 $I I_a$ 对称，而连心线正是 $\angle A$ 的内角平分线，因此交点 $S$ 必在角平分线上：A, I, S, Iₐ 四点共线！
           由角平分线定理：$SC = \frac{ab}{b+c}, SB = \frac{ac}{b+c}$，
           故 $SA_1 = \frac{1}{2}(SC - SB) = \frac{a(b - c)}{2(b + c)}$。

## 步骤 3：中位线交公切线，相似三角形导出距离比例

连接中位线 A₁B₁（$\parallel AB$）与 A₁C₁（$\parallel AC$），分别与公切线 $B'C'$ 交于 B″ 与 C″。
           由对称性，切线段长 $AC' = b \implies BC' = b - c$；同理 $CB' = b - c$。
           利用中位线平行构建相似三角形：
           因 $A_1B″ \parallel BC'$，故 $\triangle SA_1B″ \sim \triangle SBC'$，从而：
           $\frac{A_1B″}{BC'} = \frac{SA_1}{SB} \implies \frac{A_1B″}{b-c} = \frac{\frac{a(b-c)}{2(b+c)}}{\frac{ac}{b+c}} = \frac{b-c}{2c} \implies A_1B″ = \frac{(b-c)^2}{2c}$。
           同理由 $\triangle SA_1C″ \sim \triangle SCB'$ 得 $A_1C″ = \frac{(b-c)^2}{2b}$。

## 步骤 4：建立以 A₁ 为中心、半径 (b-c)/2 的反演变换

注意到中位线长 $A_1B_1 = \frac{c}{2}, A_1C_1 = \frac{b}{2}$。将它们与前式相乘：
           A₁B″ · A₁B₁ $= \frac{(b-c)^2}{2c} \cdot \frac{c}{2} = \left(\frac{b-c}{2}\right)^2$，
           A₁C″ · A₁C₁ $= \frac{(b-c)^2}{2b} \cdot \frac{b}{2} = \left(\frac{b-c}{2}\right)^2$。
           由此建立以 A₁ 为中心、半径为 R_inv = \frac{1}{2}(b-c) 的反演变换：
           中点 B₁ 的反演像是 B″，中点 C₁ 的反演像是 C″！
           反演圆恰好通过两切点 $X$ 与 $X_a$。

## 步骤 5：九点圆反演为公切线 B'C'，切圆 I 于点 T

根据反演几何性质：
           1. 九点圆经过反演中心 $A_1$，且经过 $B_1, C_1$。其反演像为过 $B″, C″$ 的直线，即内公切线 B'C'！
           2. 线段 $A_1X$ 切圆 $I$ 于 $X$，切线长 $A_1X = R_inv$。故圆 $I$ 与反演圆正交，圆 I 的反演像就是它自身！
           3. 公切线 $B'C'$ 切圆 $I$ 于点 $T'$，反演变换保持相切性，故九点圆必与圆 $I$ 相切！
           其切点 T 正是 $T'$ 关于反演圆的像！九点圆与内切圆外切获证。

## 步骤 6：同理与旁切圆相切，费尔巴哈定理完整获证

同理，切线长 $A_1X_a = R_inv$，故旁切圆 $\odot I_a$ 的反演像也是其自身！
           公切线 $B'C'$ 切旁切圆于 $T_a'$，反演后九点圆与旁切圆 $\odot I_a$ 相切于点 Tₐ（$T_a$ 为 $T_a'$ 的像）！
           同理分别以 $B_1, C_1$ 为反演中心，可证九点圆与其余两个旁切圆 $\odot I_b, \odot I_c$ 均相切。
           综上所述：任意三角形的九点圆与其内切圆和三个旁切圆都相切！著名的费尔巴哈定理获证！

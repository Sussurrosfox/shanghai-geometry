# 5 — 分步证明文字

## 步骤 0：已知条件与几何构型

设四边形 ABCD 的内切圆为圆 O，四边分别切于点 E, F, G, H。
连接对角线 AC, BD。过圆心 O 作 OM ⊥ BD 于点 M。
连接 MA, MC。求证：直线 BD 平分 ∠AMC。

## 步骤 1：① 牛顿定理与配极原则：BD 为 Q 的极线

连接 AC 与 BD 交于点 P。由牛顿定理，切点弦 EG 与 FH 亦必过点 P。
设切点连线 GH 与 FE 的延长线交于点 Q。
因为弦 EF 为切线交点 B 关于圆 O 的极线，且 Q 在直线 EF 上，由配极原则，点 Q 关于圆 O 的极线必过点 B。
同理，弦 GH 为点 D 的极线，故点 Q 关于圆 O 的极线亦过点 D。
因此，直线 BD 即为点 Q 关于圆 O 的极线。

## 步骤 2：② 自极三角形对偶：D,P,B,R 与 Q,A,P,C 共线

设切点弦 HE 与 GF 的延长线交于点 R。
在内接四边形 EFGH 中，P = EG ∩ FH，Q = GH ∩ FE，R = HE ∩ GF 构成圆 O 的自极三角形 △PQR。
由自极三角形性质，点 Q 的极线即为直线 PR。结合第 ① 步，直线 BD 与 PR 重合，即 D, P, B, R 四点共线！
同理，切线交点 A 的极线为 HE（过 R），切线交点 C 的极线为 FG（过 R）。由配极原则，点 R 的极线必过 A 与 C（即直线 AC）。
而在自极三角形中点 R 的极线即为直线 PQ，故直线 PQ 与 AC 重合，即 Q, A, P, C 四点共线！

## 步骤 3：③ 完全四边形截线：(Q, P; A, C) 为调和点列

设割线 QHG 与直线 BD 交于点 N。
由完全四边形的基本调和性质，割线上的点列 (Q, N; H, G) = -1 为调和点列。
从顶点 D 发出投影线束，知 D(Q, N; H, G) = -1 构成调和线束。
用截线 Q-A-P-C 去截该调和线束：
因为 DQ ∩ 截线 = Q，DN ∩ 截线 = P，DH (即 DA) ∩ 截线 = A，DG (即 DC) ∩ 截线 = C。
由透视投影保持调和交叉比不变，立即导出截线上的四个点构成调和点列：
(Q, P; A, C) = -1。

## 步骤 4：④ 极点连径正交：Q, M, O 三点共线且 QM ⊥ BD

连接极点 Q 与圆心 O。
由极点与极线的基本正交性质：圆心与极点的连线垂直于该极点对应的极线。因为直线 BD 为点 Q 的极线，所以必有 QO ⊥ BD。
又由已知条件，过圆心 O 作 OM ⊥ BD 且垂足为 M。
过定点 O 向直线 BD 所引垂线唯一，垂足均为 M，故垂线 OM 与垂线 QO 必在同一直线上！
由此导出：Q, M, O 三点共线，且垂线段 QM ⊥ BD（即 QM ⊥ MP），在点 M 处形成直角 ∠QMD = 90°。

## 步骤 5：⑤ 调和线束正交定理：BD 平分 ∠AMC（证毕）

以垂足 M 为顶点，连接共线的调和点列 Q, A, P, C，构成调和线束 M(Q, P; A, C) = -1。
在这一调和线束中，射线 MQ 与射线 MP 是一对共轭射线。
由第 ④ 步结论，共轭射线相互垂直，即 MQ ⊥ MP（∠QMP = 90°）。
根据调和线束正交定理：若调和线束的两条共轭射线互相垂直，则这两条共轭射线恰好平分另外两条射线所夹的角及其外角！
因此，射线 MP 必平分 ∠AMC，即 ∠PMA = ∠PMC。
由于点 P 位于直线 BD 上，射线 MP 即为直线 BD，故直线 BD 严格平分 ∠AMC。
原命题圆满得证！

# 08/2（例 1）平面几何证明分步规划

## 题目概要
设 $\bigtriangleup ABC$ 的内切圆 $I$ 与 $BC, CA, AB$ 分别切于点 $D, E, F$；$M, N$ 分别是 $\bigtriangleup ABC$ 的外接圆 $\omega$ 的弧 $AC, AB$ 的中点；$ME, NF$ 交于点 $P$；$PB, PC$ 与圆 $I$ 交于点 $X, Y$。求证：$XY \parallel BC$。

## 严格代数几何坐标体系（一般不等腰锐角三角形）
- 画布视口：`viewBox="-60 -90 810 640"`
- 基准顶点：$A = (300.00, 110.00), B = (140.00, 390.00), C = (500.00, 390.00)$
- 内心与内切圆：$I = (309.20, 291.81)$，半径 $r = 98.19$
- 切点：$D = (309.20, 390.00), E = (389.10, 234.74), F = (223.95, 243.09)$
- 外心与外接圆 $\omega$：$O = (320.00, 307.14)$，半径 $R = 198.15$
- 弧中点：
  - 弧 $AC$ 中点 $M = (481.25, 191.97)$
  - 弧 $AB$ 中点 $N = (147.95, 208.83)$
  - 弧 $BC$ 中点 $R = (320.00, 505.30)$
- 辅助外切三角形 $\bigtriangleup A'B'C'$（过 $M, N, R$ 的外切线交点）：
  - $A' = (301.44, -59.76)$
  - $B' = (-21.46, 505.30)$
  - $C' = (705.05, 505.30)$
- 位似中心与割线交点：
  - 交点 $P = ME \cap NF = (298.59, 276.75)$
  - 割线交点 $X = PB \cap \odot I = (220.00, 332.87)$
  - 割线交点 $Y = PC \cap \odot I = (398.39, 332.87)$
- **代数几何严密性校验**：
  - 位似比 $k = R / r \approx 2.018079$
  - 位似映射：$P + k(I - P) = O$，$P + k(F - P) = N$，$P + k(E - P) = M$，$P + k(D - P) = R$
  - 顶点与割线映射：$P + k(X - P) = B$，$P + k(Y - P) = C$
  - $y_X = y_Y = 332.87$，$y_B = y_C = 390.00$，斜率均为 0，严格满足 $XY \parallel BC$！

## 证明步骤设计（Step 0 ~ Step 5）

### Step 0：已知条件与几何构型
- **标题**：已知条件与几何构型
- **正文**：设锐角 $\bigtriangleup ABC$ 的内切圆 $I$ 与三边 $BC, CA, AB$ 分别切于点 $D, E, F$；外接圆记为 $\omega$。取劣弧 $AC, AB$ 的中点分别为 $M, N$。连结 $ME, NF$ 并延长相交于点 $P$。连结 $PB, PC$，它们与内切圆 $I$ 分别交于点 $X, Y$。求证：$XY \parallel BC$。
- **画面**：
  - 绘制 $\bigtriangleup ABC$ 及其外接圆 $\omega$、内切圆 $I$；
  - 标出切点 $D, E, F$、弧中点 $M, N$、交点 $P$ 以及割线与内切圆交点 $X, Y$；
  - 绘制线段 $ME, NF$（虚线引申相交）、射线 $PB, PC$ 以及目标待证线段 $XY$。

### Step 1：作外接圆的外切三角形 $\bigtriangleup A'B'C'$
- **标题**：作过弧中点的外切三角形 $\bigtriangleup A'B'C'$
- **正文**：设弧 $BC$ 的中点为 $R$。过外接圆 $\omega$ 上的三点 $N, R, M$ 分别作圆 $\omega$ 的切线，切线两两相交依次构成 $\bigtriangleup A'B'C'$，使得切点 $N \in A'B'$，$R \in B'C'$，$M \in C'A'$。外接圆 $\omega$ 即为 $\bigtriangleup A'B'C'$ 的内切圆。
- **画面**：
  - 点亮弧中点 $R$；
  - 绘制外接圆 $\omega$ 在 $N, M, R$ 处的切线，构成大三角形 $\bigtriangleup A'B'C'$（橙色线框）；
  - 标出顶点 $A', B', C'$ 以及外切点 $N, M, R$。

### Step 2：利用垂径定理证明三组对应边平行
- **标题**：利用垂径定理证明对应边平行
- **正文**：记外接圆 $\omega$ 的圆心为 $O$。因为 $A'B'$ 是圆 $\omega$ 在 $N$ 处的切线，所以 $ON \bot A'B'$。又因为点 $N$ 是弧 $AB$ 的中点，由垂径定理知直径所在直线 $ON \bot AB$。因此 $AB \parallel A'B'$。同理，由 $OM \bot C'A'$ 且 $OM \bot CA$ 可得 $CA \parallel C'A'$；由 $OR \bot B'C'$ 且 $OR \bot BC$ 可得 $BC \parallel B'C'$。
- **画面**：
  - 高亮外心 $O$ 与垂直线段 $ON, OM, OR$；
  - 在 $N$ 与线段 $AB$ 上显示直角符号；
  - 高亮平行线对：$AB$ 与 $A'B'$、$BC$ 与 $B'C'$、$CA$ 与 $C'A'$，并带有同向平行箭头。

### Step 3：确立两三角形的外位似映射
- **标题**：确立 $\bigtriangleup ABC$ 与 $\bigtriangleup A'B'C'$ 的位似映射
- **正文**：由于 $\bigtriangleup ABC$ 与 $\bigtriangleup A'B'C'$ 的三组对应边分别平行且同向，故存在唯一的正位似变换 $\mathcal{H}$（位似比 $k = R/r > 1$），将点 $A, B, C$ 分别映射为 $A', B', C'$。在此位似变换下，$\bigtriangleup ABC$ 的内切圆 $I$ 必然映射为 $\bigtriangleup A'B'C'$ 的内切圆，即外接圆 $\omega$。从而切点 $F \in AB$ 映射为切点 $N \in A'B'$，切点 $E \in CA$ 映射为切点 $M \in C'A'$，切点 $D \in BC$ 映射为切点 $R \in B'C'$。
- **画面**：
  - 填充轻微半透明底色的两个三角形 $\bigtriangleup ABC$ 与 $\bigtriangleup A'B'C'$；
  - 高亮对应内切圆 $I$ 与 $\omega$；
  - 用同种颜色标记对应切点对 $(F, N)$、$(E, M)$、$(D, R)$。

### Step 4：证明点 $P$ 为位似中心与顶点共线
- **标题**：交点 $P$ 即为位似中心，三线共点
- **正文**：在位似变换 $\mathcal{H}$ 中，任何一对对应点的连线必过位似中心。由于 $F \mapsto N$ 且 $E \mapsto M$，直线 $NF$ 与 $ME$ 必交于位似中心。而已知 $ME \cap NF = P$，故 $P$ 即为该位似变换的位似中心！由此立得：对应顶点与位似中心共线，即 $P, A, A'$ 共线；$P, B, B'$ 共线；$P, C, C'$ 共线。
- **画面**：
  - 强化高亮直线 $ME$ 与 $NF$，交于醒目的位似中心 $P$；
  - 绘制贯穿 $P, B, B'$ 的放射状辅助线与贯穿 $P, C, C'$ 的放射状辅助线；
  - 闪耀点 $P$ 的特殊标记。

### Step 5：圆 $I$ 映射为圆 $\omega$，得出 $XY \parallel BC$
- **标题**：位似映射导出 $XY \parallel BC$（原命题得证）
- **正文**：由于位似变换以 $P$ 为中心将圆 $I$ 映射为圆 $\omega$，射线 $PB$ 与圆 $I$ 的交点为 $X$，而 $B$ 恰为外接圆 $\omega$ 上的点，因此射线 $PB$ 上的内切圆点 $X$ 在该变换下的对应点恰为外接圆点 $B$（即 $\mathcal{H}(X) = B$）。同理，射线 $PC$ 上的内切圆点 $Y$ 的对应点恰为外接圆点 $C$（即 $\mathcal{H}(Y) = C$）。于是，线段 $XY$ 在位似变换下映射为线段 $BC$。由位似变换保持直线方向不变的基本性质，直接得出 $XY \parallel BC$。原命题得证！
- **画面**：
  - 高亮线段 $XY$ 与线段 $BC$（加粗青色与紫色高亮对比）；
  - 射线 $PX \to B$ 与 $PY \to C$ 路径动态发光；
  - 标出 $XY$ 与 $BC$ 处的双箭头平行标记，圆满完成证明。

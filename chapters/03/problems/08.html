25  例 8：外心、垂心反射与西姆松线共线

第 3 讲 点共线与线共点 竞赛难度 点共线与线共点

25.1 题目

设 O, H 分别是锐角 \triangle {ABC} 的外心和垂心,证明: 在边 {BC},{CA},{AB} 上分别存在点 D, E, F ,使得 {OD} + {DH} = {OE} + {EH} = {OF} + {FH} 且 {AD},{BE},{CF} 三线共点.

25.2 参考解答

重要标准解答

如图 3-7,设 H 关于 {BC},{CA},{AB} 的对称点分别为 {A}^{\prime },{B}^{\prime },{C}^{\prime } ,则 {A}^{\prime },{B}^{\prime },{C}^{\prime } 均在 \triangle {ABC} 的外接圆圆 O 上. 设 O{A}^{\prime } 与 {BC} 交于 D, O{B}^{\prime } 与 {CA} 交于 E, O{C}^{\prime } 与 {AB} 交于 F ,则 D, E, F 满足要求.

设直线 {AO},{BO},{CO} 与 {BC},{CA},{AB} 的交点分别为 {D}^{\prime },{E}^{\prime },{F}^{\prime } . 由于 {DH} = D{A}^{\prime } ,则 {OD} + {DH} = \; {OD} + D{A}^{\prime } = R ,其中 R 为 \triangle {ABC} 的外接圆半径. 同理有 {OE} + {EH} = {OF} + {FH} = R .

由 \angle {BAO} = {90}^{ \circ } - \angle {ACB} = \angle {CA}{A}^{\prime } 得 \angle {BO}{D}^{\prime } = \angle {COD} ，结合 {OB} = {OC} ， \angle {OB}{D}^{\prime } = \angle {OCD} ,有 \triangle {OB}{D}^{\prime } \cong \triangle {OCD} ,于是 B{D}^{\prime } = {CD} . 同理, C{E}^{\prime } = {AE} , A{F}^{\prime } = {BF} .

对 \triangle {ABC} 及点 O ,应用塞瓦定理,得

\frac{B{D}^{\prime }}{{D}^{\prime }C} \cdot \frac{C{E}^{\prime }}{{E}^{\prime }A} \cdot \frac{A{F}^{\prime }}{{F}^{\prime }B} = 1,

即

\frac{CD}{DB} \cdot \frac{BF}{FA} \cdot \frac{AE}{EC} = 1.

由塞瓦定理逆定理,知 {AD},{BE},{CF} 三线共点.

注: 条件 {OD} + {DH} = {OE} + {EH} = {OF} + {FH} 容易联想到 \triangle {ABC} 有以 O ， H 为焦点的内切椭圆，只需验证切点满足第二个条件即可，这可用塞瓦定理证明.

25.3 解题思路与分析

注记思路还原与分析

这份教材证明之所以显得“费解”，是因为它采用了典型的“倒果为因”式写法——直接把最终构造抛出来，却把背后最关键的几何直觉、对称性本质以及高观点命题背景全部藏在了幕后（只在最后的“注”里留了一句半遮半掩的提示）。

我们可以分三个层次，把这道题从“初等破题直觉”、“全等背后的对称本质”一直还原到“命题人的高观点背景”。

25.3.1 第一层：如何想到构造点 D？（“将军饮马”与垂心反射定理）

题目要求在边 BC, CA, AB 上找点 D, E, F，使得 OD + DH = OE + EH = OF + FH。 面对这个条件，初等几何有两个极其自然的条件反射：

  1. 看到“定直线上一点到两定点距离之和” \implies 想到对称翻折（“将军饮马”模型） 点 O, H 是定点，D 在定直线 BC 上。要研究折线段 OD + DH 的长度，最标准的动作就是把其中一个定点关于 BC 对称翻折，化折为直。
  2. 翻折谁？ \implies 垂心关于边的对称点在外接圆上 平面几何中有一个极为经典的结论：垂心 H 关于 \triangle ABC 三边的对称点 A', B', C' 恰好都落在外接圆 \odot O 上。 一旦把 H 对称到 A'，就有 DH = DA'，从而： OD + DH = OD + DA'
  3. 如何让三边上的距离之和相等？ \implies 取共线时的定值 R 对于一般的点 D，O, D, A' 构成三角形，算不出简洁的长度；但当且仅当 O, D, A' 三点共线时（即取 D = OA' \cap BC），折线被拉直，OD + DA' 取得最小值 OA'。 而因为 A' 在 \odot O 上，OA' 就是外接圆半径 R！ 由于 R 对三条边是完全对称的常数，只要我们在三边上都取这个“拉直点”，就能不费吹灰之力地同时满足： OD + DH = OE + EH = OF + FH = R

25.3.2 第二层：如何想到引入 D' 并证全等？（中垂线对称与“等距共轭”）

教材证明中最让人拍案惊奇又摸不着头脑的一步是：为什么突然引出 AO 与 BC 的交点 D'，并通过导角证明 \triangle OBD' \cong \triangle OCD，得出 BD' = CD？

其实，教材里的导角和全等掩盖了一个极其直观的轴对称关系：

  • 对称轴是 BC 的垂直平分线： 设 BC 的中点为 M，则 OM \perp BC。同时，AA' 是 BC 边上的高线，所以 AA' \perp BC。因此： OM \parallel AA'
  • 等腰三角形中的平行线带来对称性： 在等腰 \triangle OAA' 中（因为 OA = OA' = R），底角相等，即 \angle OAA' = \angle OA'A。 由于 OM \parallel AA'，利用内错角与同位角相等可知：直线 OA（即直线 OD'）与直线 OA'（即直线 OD）关于 BC 的中垂线 OM 是严格轴对称的！
  • 结论自然涌现（等距共轭）： 既然直线 OD' 和 OD 关于 BC 的中垂线对称，那么它们与线段 BC 的交点 D' 和 D 必然也关于中垂线对称——也就是说，D 和 D' 到 BC 两端点的距离互换，即 BD' = CD！

在三角形几何中，边 BC 上满足 BD' = CD 的两个点 D, D' 称为等距共轭点（Isotomic Conjugates）。 * 因为 AD', BE', CF' 交于一点 O，满足塞瓦定理 \frac{BD'}{D'C} \cdot \frac{CE'}{E'A} \cdot \frac{AF'}{F'B} = 1； * 将每个分点替换为它在对应边上的对称点 D, E, F 后，分式分子分母恰好对应重排，塞瓦乘积依然等于 1。因此 AD, BE, CF 必然也三线共点（该交点即为外心 O 的等距共轭点）。

教材为了写成标准的初等几何格式，没有引入中点 M 和中垂线对称，而是把“关于 OM 对称”硬生生改写成了导角和 \triangle OBD' \cong \triangle OCD，这才让读者觉得像变魔术。

25.3.3 第三层：命题人的“上帝视角”（内切椭圆、光学性质与布里安松定理）

教材最后的“注”揭开了这道题真正的身世。这道题并不是凭空凑出来的，而是将射影几何与圆锥曲线中的经典定理翻译成了初等几何语言：

  1. 等角共轭点与内切圆锥曲线（麦克比斯内切椭圆）： 在三角形几何中有一个深刻定理：三角形的任意一对等角共轭点，都是该三角形某条内切圆锥曲线的两个焦点。 外心 O 和垂心 H 是 \triangle ABC 中最著名的一对等角共轭点（\angle BAO = \angle CAH）。以 O, H 为焦点、与 \triangle ABC 三边都相切的椭圆，在几何学中称为麦克比斯内切椭圆（MacBeath Inconic）。
  2. 椭圆的定义与光学性质（对应第一部分）：
  • 设该内切椭圆与三边 BC, CA, AB 的切点分别为 D, E, F。因为 D, E, F 都在椭圆上，根据椭圆的第一定义（椭圆上任意一点到两焦点距离之和等于长轴长 2a），自然有： OD + DH = OE + EH = OF + FH = 2a
  • 根据椭圆的光学性质（从焦点 O 发出的光线经切线 BC 反射后必经过另一焦点 H），切点 D 恰好就是边 BC 上使 OD + DH 最短的点，也就是 O 与 H 的对称点 A' 的连线与 BC 的交点！由此还顺便算出了该内切椭圆的长轴长 2a = OA' = R（事实上，它的辅助圆正是半径为 R/2 的九点圆）。
  1. 布里安松定理（对应第二部分）： 布里安松定理（Brianchon’s Theorem）的退化形式指出：若一个圆锥曲线内切于 \triangle ABC，切点分别为 D, E, F，则连接顶点与对边切点的三条线段 AD, BE, CF 必三线共点。（我们熟知的“内切圆切点与顶点连线交于热尔岗点 Gergonne Point”就是它在圆上的特例。）

总结命题与解题的脉络： 命题人从以 O, H 为焦点的内切椭圆出发，隐去了“椭圆”和“相切”的概念，把切点 D, E, F 包装成了初等条件“OD + DH = OE + EH = OF + FH”；而在撰写初等解答时，用“对称拉直（将军饮马）”还原了椭圆的光学性质来定位切点 D, E, F，再用“关于边中垂线对称（等距共轭）+ 塞瓦定理”给出了布里安松定理在该特例下的纯平面几何证法。

25.4 分步证明

提示分步推理与几何步骤

25.4.1 步骤 0：已知条件与几何构型

给定锐角 \triangle ABC，其外心为 O（外接圆半径为 R），垂心为 H（三条高线的交点）。 求证：在边 BC, CA, AB 上分别存在点 D, E, F，满足： 1. 折线长恒等：OD + DH = OE + EH = OF + FH 2. 连线共点：AD, BE, CF 三线共点。

25.4.2 步骤 1：垂心对称点落在外接圆上

设垂心 H 关于三边 BC, CA, AB 的对称点分别为 A', B', C'。 垂心经典性质： \angle BHC = 180^\circ - \angle A。 因为 A' 与 H 关于 BC 对称，所以 \triangle B A' C \cong \triangle BHC，从而： \angle B A' C = \angle BHC = 180^\circ - \angle A。 由于四边形 A B A' C 对角互补，A' 必落在 \triangle ABC 的外接圆 \odot O 上！ 同理，B', C' 亦均落在外接圆 \odot O 上。

25.4.3 步骤 2：射线确定点 D, E, F 且折线长恒等于 R

连结圆心 O 与外接圆上的对称点： 设线段 OA' 与 BC 交于 D；OB' 与 CA 交于 E；OC' 与 AB 交于 F。 由轴对称性知 DH = DA'，因此折线长可直接拉直： OD + DH = OD + DA' = OA' = R（外接圆半径）！ 同理有： OE + EH = OB' = R，OF + FH = OC' = R。 第一组等式条件天然获证！

25.4.4 步骤 3：外心射线交点与全等对称关系

设直线 AO, BO, CO 与三边分别交于 D', E', F'。 在圆周角与圆心角关系中： \angle BAO = 90^\circ - \angle ACB = \angle CAA'，由此可得顶角： \angle BOD' = \angle COD。 又在等腰 \triangle OBC 中 OB = OC，底角 \angle OBD' = \angle OCD = 90^\circ - \angle A。 由角边角 (ASA) 判定得全等： \triangle OBD' \cong \triangle OCD！ 由此得对应边等长：BD' = CD。 同理可证：CE' = AE，AF' = BF。

25.4.5 步骤 4：塞瓦定理比值代换

因为直线 AD', BE', CF' 共点于外心 O，对 \triangle ABC 应用塞瓦定理： \frac{BD'}{D'C} \cdot \frac{CE'}{E'A} \cdot \frac{AF'}{F'B} = 1 利用 Step 3 证得的等长关系： BD' = CD（故分母 D'C = a - BD' = a - CD = DB）； 同理 CE' = AE, E'A = EC 以及 AF' = BF, F'B = FA。 将等长对应代换入塞瓦式，即得： \frac{CD}{DB} \cdot \frac{AE}{EC} \cdot \frac{BF}{FA} = 1

25.4.6 步骤 5：塞瓦定理逆定理得证三线共点

将比值等式整理为逆时针顺序： \frac{BD}{DC} \cdot \frac{CE}{EA} \cdot \frac{AF}{FB} = 1 由塞瓦定理逆定理： 直线 AD, BE, CF 必三线共点于点 K！ 至此，点 D, E, F 不仅满足折线长恒等于外接圆半径 R，且连线三线共点全部获证。

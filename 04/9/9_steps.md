# 9 — 分步证明文字

## 步骤 0：已知条件与几何构型

在直角 Rt △ABC 中，∠C = 90°，CD ⊥ AB 于垂足 D。
    记两个直角子三角形 △ACD 与 △BCD 的内心分别为 I₁ 和 I₂。
    连接两内心得直线 I₁I₂，与两直角边 CA, CB 分别交于点 M 与 N。
    目标：定量研究两三角形面积之比，证明不等式 S△ABC ≥ 2 S△CMN

## 步骤 1：母子直角三角形相似与旋转

在直角三角形中，高线将原三角形分成两个与自身均相似的直角三角形：
    易知 ∠CAD = 90° - ∠ACD = ∠BCD，故有
    Rt △DAC ∼ Rt △DCB
    对应边成比例：AD / CD = CD / BD = AC / BC。
    以高线垂足 D 为旋转中心：
    将 △DCB 绕点 D 逆时针旋转 90° 并进行比例伸缩，即可与 △DAC 完全重合。

## 步骤 2：内心相似导出夹角 45°

因为 I₁, I₂ 分别为直角 ∠ADC, ∠BDC 的内角平分线上的点：
    ∠CDI₁ = 45°,  ∠CDI₂ = 45° ⟹ ∠I₁DI₂ = 90° = ∠BDC
    由母子三角形相似，内心的相对位置完全对应，故对应边成比例：
    I₂D / I₁D = BD / CD
    由两边成比例且夹角为直角，得 △DCB ∼ △DI₁I₂！
    由于 ∠CDI₂ = 45°，此相似相当于将 △DCB 绕点 D 逆时针旋转 45°。
    因此，对应直线 I₁I₂ 与 CB 的夹角即为该旋转角，故 ∠CNM = 45°。

## 步骤 3：确定 △CMN 为等腰直角三角形

在 △CMN 中，已知顶点角 ∠C = 90°（即 CA ⊥ CB）。
    由上一步推导已知割线与直角边的夹角：
    ∠CNM = 45°
    从而在直角 Rt △CMN 中，另一个锐角为：
    ∠CMN = 90° - ∠CNM = 45°
    两底角相等且均为 45°，因此 △CMN 是等腰直角三角形，得出对应直角边相等：
    CM = CN

## 步骤 4：全等判定导出 CM = CN = CD

连接辅助线 CI₂，考察 △I₂CD 与 △I₂CN：
    ① CI₂ 为 △BCD 的内角平分线 ⟹ ∠I₂CD = ∠I₂CN；
    ② CI₂ 为两三角形的公共边；
    ③ 由内心性质 ∠CDI₂ = 45°，由前一步 ∠CNI₂ = ∠CNM = 45°，故 ∠CDI₂ = ∠CNI₂ = 45°。
    由 AAS（角-角-边）全等判据，立得：
    △I₂CD ≅ △I₂CN
    因此对应边相等：CD = CN。
    结合上一步的 CM = CN，立即得到关键等长链条：
    CM = CN = CD

## 步骤 5：面积比化简与均值不等式

计算两个三角形的面积：
    S△ABC = ½ · AB · CD，
    S△CMN = ½ · CM · CN = ½ · CD²。
    两面积相比，可消去高 CD：
    S△ABC / S△CMN = (AB · CD) / (CM · CN) = AB / CD
    在直角 Rt △ABC 中，取斜边中点 O（外心），斜边中线长为 CO = ½ AB。
    由垂线段最短（或均值不等式 AB = AD + BD ≥ 2√(AD · BD) = 2CD）：
    CD ≤ CO = ½ AB  ⟹  AB / CD ≥ 2
    因此：
    
      S△ABC ≥ 2 S△CMN
    
    等号成立当且仅当 AD = BD（即 Rt △ABC 为等腰直角三角形）。证明完毕！

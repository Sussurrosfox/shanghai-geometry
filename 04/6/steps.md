# 题目 04/6.md（例 5）分步证明规划：四边形 AXYD 是平行四边形

## 题目概要
- **命题**：在圆内接四边形 $ABCD$ 中，$X, Y$ 分别为 $\triangle ABC, \triangle BCD$ 的垂心。证明：四边形 $AXYD$ 是平行四边形。
- **图形核心要素**：
  - 外接圆 $\odot O$；
  - 圆内接四边形 $ABCD$；
  - 垂心 $X$（$\triangle ABC$）与垂心 $Y$（$\triangle BCD$）；
  - 垂心关于公共边 $BC$ 的对称点 $X', Y'$；
  - 平行四边形 $AXYD$。

---

## 分步证明结构规划（0 ~ 5 共 6 步）

### 步骤 0：已知条件与图形构型
- **标题**：已知条件与图形构型
- **数学逻辑**：
  - 给定圆内接四边形 $ABCD$，其四个顶点共圆于 $\odot O$。
  - $X$ 是 $\triangle ABC$ 的垂心，$Y$ 是 $\triangle BCD$ 的垂心。
  - 目标：证明四边形 $AXYD$ 是平行四边形。
- **画面**：
  - 绘制外接圆 $\odot O$；
  - 绘制四边形 $ABCD$ 边线（实线）；
  - 绘制辅助对角线 $AC, BD$（浅灰细线）；
  - 绘制垂心 $X, Y$（高亮实心圆点）；
  - 绘制所有顶点及垂心标签 $A, B, C, D, X, Y$。
- **色彩规划**：
  - 外接圆：`#94a3b8` 细实线；
  - 四边形 $ABCD$：`#334155`（粗 2px）；
  - 垂心 $X$：`#2563eb`（蓝色）；
  - 垂心 $Y$：`#7c3aed`（紫色）。

---

### 步骤 1：垂心关于对边的反射点落在外接圆上
- **标题**：① 垂心反射性质 ⇒ 对称点 $X', Y'$ 落在外接圆上
- **数学逻辑**：
  - 设 $X, Y$ 关于边 $BC$ 的轴对称点分别为 $X', Y'$。
  - **垂心经典性质**：三角形垂心关于任何一边的对称点落在该三角形的外接圆上。
  - **简证**：在 $\triangle ABC$ 中，由垂心角关系知 $\angle BXC = 180^\circ - \angle BAC$；轴对称变换后，$\angle BX'C = \angle BXC = 180^\circ - \angle BAC$。因此四边形 $ABX'C$ 对角互补，点 $X'$ 落在外接圆 $\odot O$ 上！
  - 同理，$\triangle BCD$ 的外接圆亦为 $\odot O$，故 $Y$ 关于 $BC$ 的对称点 $Y'$ 亦落在外接圆 $\odot O$ 上。
  - 由轴对称保距性：$X'Y' = XY$，且线段 $XY$ 与 $X'Y'$ 关于直线 $BC$ 轴对称。
- **画面**：
  - 新增直线 $BC$ 的延长线（对称基准轴）；
  - 新增垂直对称引线 $XX'$ 与 $YY'$（青色虚线）；
  - 标出垂足处的垂直标记 $\llcorner$ 与中点等长刻度；
  - 新增圆上对称点 $X', Y'$ 及其标签；
  - 连接并高亮线段 $X'Y'$（绿色粗虚线）；
  - 擦除淡化对角线 $AC, BD$。
- **色彩规划**：
  - 对称引线：`#0891b2`（青色虚线）；
  - 镜像点 $X', Y'$：`#059669`（绿色实心点）；
  - 镜像线段 $X'Y'$：`#059669`（绿色粗虚线）。

---

### 步骤 2：高线共线与垂直判定 ⇒ 两对平行线
- **标题**：② 高线共线与垂直判定 ⇒ 两对平行线
- **数学逻辑**：
  - 由垂心定义，$AX \perp BC$。
  - 由对称定义，$XX' \perp BC$。
  - 平面内过一点引已知直线的垂线唯一，因此点 $A, X, X'$ 三点共线，且整条割线 $AX' \perp BC$。
  - 同理，点 $D, Y, Y'$ 三点共线，且整条割线 $DY' \perp BC$。
  - 由此直接导出两组极关键的平行关系：
    1. **圆内弦平行**：弦 $AX' // DY'$（均垂直于 $BC$）；
    2. **四边形对边平行**：线段 $AX // DY$（均垂直于 $BC$）。
- **画面**：
  - 贯通绘制垂直线段 $AX'$ 与 $DY'$（蓝色高亮）；
  - 在直线与 $BC$ 交点处标出清晰直角符号；
  - 在线段 $AX$ 与 $DY$ 上标出平行箭头标记；
  - 擦除步骤 1 的细部等长刻度，凸显垂直与平行关系。
- **色彩规划**：
  - 高线/平行弦：`#2563eb`（蓝色）；
  - 直角标记：`#dc2626`（红色）；
  - 平行标记：`#2563eb`。

---

### 步骤 3：圆内平行弦夹等腰梯形 ⇒ 边长等长 $AD = XY$
- **标题**：③ 圆内平行弦夹等腰梯形 ⇒ 边长等长 $AD = XY$
- **数学逻辑**：
  - 在外接圆 $\odot O$ 中，弦 $AX' // DY'$。
  - **圆内接梯形性质**：圆内两平行弦所夹的圆内接四边形必然是等腰梯形（或矩形）。
  - 因此四边形 $AX'Y'D$ 是等腰梯形，其两腰相等：$AD = X'Y'$。
  - 结合步骤 1 中轴对称得出的 $X'Y' = XY$，立即得到：$$AD = XY$$
  - 至此，四边形 $AXYD$ 已有一组对边平行（$AX // DY$），另一组对边长度相等（$AD = XY$）。
- **画面**：
  - 填充等腰梯形 $AX'Y'D$ 的半透明浅绿色遮罩；
  - 高亮显示等长线段 $AD$、$X'Y'$ 与 $XY$；
  - 在 $AD$、$X'Y'$、$XY$ 三条线段上分别打上相同的等长刻度线；
  - 擦除多余的高线延展，突出梯形两腰与 $XY$ 的等长关系。
- **色彩规划**：
  - 等腰梯形填充：`rgba(5, 150, 105, 0.08)`；
  - 等长三边 $AD, X'Y', XY$：`#059669`（绿色高亮）；
  - 等长刻度：`#059669`。

---

### 步骤 4：对称轴分析与两次反射复合 ⇒ 向量平移
- **标题**：④ 两次平行轴反射复合 ⇒ 线段平移 $XY \to AD$
- **数学逻辑**：
  - 等腰梯形 $AX'Y'D$ 具有一条垂直平分底边 $AX', DY'$ 的对称轴，该轴必然通过外心 $O$（即圆的一条直径），记为 $L_{\text{sym}}$。
  - 由于底边 $AX' \perp BC$，故对称轴直径 $L_{\text{sym}} // BC$！
  - 考察图形中的两次对称变换：
    1. **第一次反射**：线段 $XY$ 关于直线 $BC$ 对称得到线段 $X'Y'$；
    2. **第二次反射**：线段 $X'Y'$ 关于直径 $L_{\text{sym}}$ 对称得到线段 $AD$。
  - **几何变换复合定理**：关于两条平行直线（$BC$ 与 $L_{\text{sym}}$）先后进行两次反射，其复合变换等价于纯平移变换！
  - 平移方向垂直于对称轴（即平行于 $AX$），平移距离为两平行轴间距的 2 倍。
- **画面**：
  - 绘制平行对称轴直径 $L_{\text{sym}}$（橙色点划线穿过圆心 $O$）；
  - 突出显示基准平行轴 $BC$ 与 $L_{\text{sym}}$ 的平行状态；
  - 绘制从 $X \to A$ 以及 $Y \to D$ 的平移运动导向虚线；
  - 擦除等腰梯形填充，强化平移变换的动态过程。
- **色彩规划**：
  - 对称轴直径 $L_{\text{sym}}$：`#ea580c`（橙色点划线）；
  - 平移运动导向线：`#7c3aed`（紫色虚线）。

---

### 步骤 5：得出最终结论 ⇒ 四边形 $AXYD$ 为平行四边形
- **标题**：⑤ 平移保持平行与方向 ⇒ $AXYD$ 是平行四边形
- **数学逻辑**：
  - 因为线段 $AD$ 是由线段 $XY$ 经纯平移变换得到的，所以对应向量相等：$$\vec{XY} = \vec{AD}$$
  - 这保证了线段 $XY$ 与 $AD$ 不仅长度相等，而且方向严格平行：$XY // AD$！
  - 同时，我们在步骤 2 中已知 $AX // DY$。
  - 两组对边分别平行的四边形必为平行四边形；或者一组对边平行且相等的四边形为平行四边形。
  - 因此，四边形 $AXYD$ 是平行四边形！命题得证。
- **画面**：
  - 完整呈现四边形 $AXYD$（高亮蓝色边框，浅蓝半透明填充）；
  - 在两组对边上分别标出双对边平行标记（单箭头与双箭头）；
  - 擦除所有临时对称轴 $L_{\text{sym}}$、镜像点 $X', Y'$ 及引线；
  - 恢复并突出四边形 $ABCD$ 与外接圆作为整体基准背景。
- **色彩规划**：
  - 平行四边形 $AXYD$：边线 `#2563eb`（粗 3px），填充 `rgba(37, 99, 235, 0.12)`；
  - 平行标记：对边 $AX // DY$（单箭头 `#2563eb`），对边 $XY // AD$（双箭头 `#059669`）。

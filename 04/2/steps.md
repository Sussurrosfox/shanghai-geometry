# 04/2.md（例 1）几何证明交互分步规划

## 题目信息
- **命题**：点 $D$ 是 $\triangle ABC$ 的边 $BC$ 上一点，使得 $AD > BC$；$E$ 为 $AC$ 上一点，使得 $\frac{AE}{EC} = \frac{BD}{AD - BC}$。证明：$AD > BE$。
- **核心思想**：通过构造延长线段与平行四边形，将线段 $BE$ 平移至 $DK$，使得 $AD$ 与 $BE$ 转化为同一三角形 $\triangle ADK$ 的两边，再结合等腰三角形底角与外角不等式，通过「大角对大边」完成证明。

---

## 分步规划一览（共 6 步：Step 0 ~ Step 5）

### Step 0: 已知条件与图形
- **步骤标题**：已知条件与问题导入
- **数学逻辑**：
  给定 $\triangle ABC$。点 $D$ 在边 $BC$ 上，满足 $AD > BC$；点 $E$ 在边 $AC$ 上，满足 $\frac{AE}{EC} = \frac{BD}{AD - BC}$。
  求证：$AD > BE$。
  线段 $AD$ 与 $BE$ 既不共端点，也不在同一个三角形中，常规几何方法难以直接比较其长度。
- **新增图元**：
  - 基准图形：$\triangle ABC$ 边框（实线）
  - 线段 $AD$（蓝色实线）
  - 线段 $BE$（橙色实线）
  - 顶点与分点：$A, B, C, D, E$（带防遮挡标签）
- **擦除图元**：无
- **色彩规划**：
  - 基础轮廓：深灰 `#334155`
  - 目标线段 $AD$：蓝色 `#2563eb`
  - 目标线段 $BE$：橙色 `#ea580c`

---

### Step 1: 构造关键线段 $CF$ 与 $FG$
- **步骤标题**：① 延长底边：构造关键线段 CF 与 FG
- **数学逻辑**：
  延长边 $BC$ 至点 $F$，使得 $CF = AD - BC$；
  再延长至点 $G$，使得 $FG = BD$。
  此时有：
  $$BC + CF = BC + (AD - BC) = AD$$
  $$DG = DC + CF + FG = (DC + BD) + CF = BC + CF = AD$$
- **新增图元**：
  - 延长线段 $CF, FG$（虚线/实线，沿水平方向向右延伸）
  - 新增点：$F, G$ 及标签
  - 等长刻度标记：在 $BD$ 与 $FG$ 上标注相同的双刻度线
- **擦除图元**：保持基础图形
- **色彩规划**：
  - 延长线：青色 `#0891b2`
  - 等长刻度：青色 `#0891b2`

---

### Step 2: 比例转化导出平行线 $EF \parallel AG$
- **步骤标题**：② 比例转化：由平行线分线段成比例得 EF ∥ AG
- **数学逻辑**：
  由题设条件 $\frac{AE}{EC} = \frac{BD}{AD - BC}$，
  代入构造关系 $BD = FG$ 及 $AD - BC = CF$，得：
  $$\frac{AE}{EC} = \frac{FG}{CF}$$
  在 $\triangle ACG$ 中，点 $E$ 在边 $AC$ 上，点 $F$ 在边 $CG$ 上，根据平行线分线段成比例定理的逆定理，知：
  $$EF \parallel AG$$
- **新增图元**：
  - 辅助线段 $EF$（蓝色虚线加粗）
  - 辅助线段 $AG$（蓝色虚线加粗）
  - 平行箭头标记：在 $EF$ 与 $AG$ 上标注平行箭头
- **擦除图元**：擦除刻度标记
- **色彩规划**：
  - 平行线段 $EF$ 与 $AG$：皇家蓝 `#2563eb`

---

### Step 3: 平行四边形平移：将 $BE$ 平移至 $DK$
- **步骤标题**：③ 平移构造：平行四边形 BDKE 使 BE = DK
- **数学逻辑**：
  过点 $E$ 作 $EK \parallel CG$（即平行于底边直线 $BC$）交 $AG$ 于点 $K$。
  因为 $EF \parallel KG$ 且 $EK \parallel FG$，所以四边形 $FEKG$ 为平行四边形，故 $EK \xlongequal{\parallel} FG$。
  又因 $FG = BD$ 且在同一直线上，所以 $EK \xlongequal{\parallel} BD$。
  由此知四边形 $BDKE$ 亦为平行四边形！
  连接 $DK$，则 $DK \xlongequal{\parallel} BE$，特别是 $DK = BE$。
  我们成功将线段 $BE$ 平移至 $DK$！
- **新增图元**：
  - 水平辅助线段 $EK$（虚线）
  - 点 $K$ 及标签
  - 平移线段 $DK$（橙色加粗实线）
  - 平行四边形 $BDKE$（浅橙色半透明背景高亮）
- **擦除图元**：擦除辅助线 $EF$（已完成历史使命，保持画面简洁）
- **色彩规划**：
  - 平行四边形 $BDKE$：浅橙色透明填充 `rgba(234, 88, 12, 0.12)`
  - 线段 $BE$ 与 $DK$：鲜艳橙色 `#ea580c`，标注等长单刻度

---

### Step 4: 等腰三角形底角与外角不等式
- **步骤标题**：④ 角度关系：等腰 △ADG 底角与外角不等式
- **数学逻辑**：
  计算 $DG$ 的总长：
  $$DG = DC + CF + FG = DC + CF + BD = (BD + DC) + CF = BC + (AD - BC) = AD$$
  所以 $\triangle ADG$ 是以 $D$ 为顶点的等腰三角形，两腰 $AD = DG$。
  因此其底角相等：$\angle DAK = \angle DAG = \angle G$。
  另一方面，在 $\triangle DKG$ 中，点 $K$ 在线段 $AG$ 上，边 $GK$（即 $GA$）与边 $KD$ 所夹角 $\angle AKD$ 为该三角形的外角。
  由三角形外角大于任何一个不相邻的内角知：
  $$\angle AKD > \angle G$$
  代入 $\angle G = \angle DAK$，即得：
  $$\angle AKD > \angle DAK$$
- **新增图元**：
  - 高亮等腰 $\triangle ADG$ 的两腰 $AD$ 与 $DG$（绿色加粗）
  - 角弧标记：$\angle DAK$（红色单弧）与 $\angle G$（红色单弧，表示相等）
  - 角弧标记：$\angle AKD$（紫色双弧，强调该角大于 $\angle G$）
- **擦除图元**：擦除平行四边形 $BDKE$ 的填充底色
- **色彩规划**：
  - 等腰三角形两腰 $AD, DG$：翠绿色 `#059669`
  - 相等底角 $\angle DAK, \angle G$：绯红色 `#dc2626`
  - 大外角 $\angle AKD$：紫色 `#7c3aed`

---

### Step 5: 在 $\triangle ADK$ 中大角对大边得出最终结论
- **步骤标题**：⑤ 得出结论：在 △ADK 中大角对大边 AD > BE
- **数学逻辑**：
  聚焦三角形 $\triangle ADK$：
  在 $\triangle ADK$ 中，由于 $\angle AKD > \angle DAK$，
  根据三角形中「大角对大边」的基本几何定理，角 $\angle AKD$ 所对的边大于角 $\angle DAK$ 所对的边，即：
  $$AD > DK$$
  由 Step 3 知四边形 $BDKE$ 为平行四边形，对边 $DK = BE$。
  将 $DK = BE$ 代入上述不等式，立即得到：
  $$AD > BE$$
  命题得证！
- **新增图元**：
  - 三角形 $\triangle ADK$ 高亮（浅绿色半透明填充）
  - 线段 $AD$ 强高亮（绿色加粗，标记大于符号）
  - 线段 $DK$ 与 $BE$ 同色高亮（橙色加粗，并用等长刻度标注 $BE = DK$）
  - 角弧聚焦：$\angle AKD$（紫色大角标记）与 $\angle DAK$（红色小角标记）
- **擦除图元**：擦除多余辅助角弧，突出核心三角形 $\triangle ADK$
- **色彩规划**：
  - $\triangle ADK$ 填充：`rgba(5, 150, 105, 0.1)`
  - 较大边 $AD$：翡翠绿 `#059669`
  - 较小边 $BE$ 与 $DK$：琥珀橙 `#ea580c`
